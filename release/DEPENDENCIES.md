# 发布依赖与素材核对

更新：2026-10-07。当前市场候选移除了未被 ArkTS 引用的 `libentry` 加法模板及其 CMake 构建，生产模块未声明外部包依赖。最终 APP 检查会阻止出现未登记的原生库。历史 v1.0.0 包仍包含原生模板，不能用本清单描述旧发行包。

| 项目 | 运行用途 | 数据与许可核对 |
| --- | --- | --- |
| 本仓库 ArkTS、图标 SVG/PNG 与默认封面 | 应用界面、学习工作流 | 仓库 MIT（保留 LICENSE 中的原版权声明）；正式发布者需确认素材的可分发权，发布者名称不能替代版权声明 |
| HarmonyOS / ArkUI / Ability / ArkData / CoreFileKit | 本地界面、文件选择、存储与备份文件 | 系统能力，依当前 SDK/设备提供方条款；不是额外嵌入的统计 SDK |
| 系统 OCR / PDF / 图像能力 | 用户选择资料的文字提取与阅读 | 使用场景与资源释放按真机清单核验；不宣称每台设备可用或识别百分比 |
| UniversalKeystoreKit、CryptoArchitectureKit | 密钥保护、随机数与摘要 | AES-GCM，加密密钥由 HUKS 管理；不声称每台设备均有同等级硬件安全模块 |
| NetworkKit | 用户主动授权的 AI 请求 | HTTPS、不跟随重定向；鉴权与所选文字发送至用户配置的服务，费用/留存由提供方决定 |
| DistributedServiceKit / 分布式 KV | 可选可信设备资料传递 | 在使用时申请权限，临时库系统加密，手动副本接收；与系统帐号/网络有关 |
| `@ohos/hypium` 1.0.25、`@ohos/hamock` 1.0.0 | 开发测试 | 根目录 devDependencies；生产模块无引用，发布包检查与依赖锁文件需一起复核 |

应用当前没有广告、分析统计、崩溃上传、支付、第三方帐号或团队云盘 SDK。模型服务通过协议访问，未嵌入模型权重。商店隐私标签仍须按实际使用功能填写，不能因“没有第三方 SDK”忽略用户主动发送给 AI 服务的数据。

示例课程、PDF、考试题目和截图应使用自行创作或具有分发许可的内容。不要把真实学生姓名、课表、成绩、第三方教材全文或服务密钥混入市场素材。将权属核查记录放在本地 `release/evidence/`，不要在公共 PR 中提交个人身份证明或签名材料。
