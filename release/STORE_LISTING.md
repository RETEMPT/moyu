对应候选：1.1.0（1001000），统一手机与 Pad。正式截图、发布者及最终类别需在 AGC 核对；本页不代表已上架。

## 名称与简介

名称：墨语

一句话简介：整理课程资料，阅读批注，题卡自测与复习。

## 应用介绍

墨语是一款面向校园学习的本地资料与复习工作台。把课程笔记、PDF 与图片文字整理到同一个资料库，从原文阅读到题卡自测形成连续的学习流程。

- 课程整理：建立课程分类，编辑 Markdown 笔记，选择封面、标签与双向链接。
- 阅读与校对：阅读 PDF，保留笔迹和批注，提取页面文字并人工校对；支持的设备可使用系统 OCR。
- 自测复习：手动建立题卡，查看资料来源，记录自测反馈与复习进度。
- 本地检索：按关键词查找资料，不要求注册应用帐号或配置模型。
- 资料迁移：导出课程学习备份，恢复时保留原资料并导入副本。附近可信设备传递为试用功能，依赖系统能力与组网条件。
- 可选 AI：自行配置兼容 API、Gemini 或 Anthropic 服务，用于问答、智能整理和题卡建议。默认不发送数据，授权后按所选范围调用；服务可用性和费用由提供方决定。

手机与 Pad 复用同一套资料结构与图标，按窗口宽度切换布局。手机保留首页、资料、AI 墨客、待办、图谱五项导航。学习资料保存在本机；卸载前请导出备份，换机后重新填写模型密钥。AI 结果需结合课程原文核对。

## 审核操作说明

1. 首次启动阅读说明，可选择“暂不同意，离线使用”；不要求登录或填写 Key。
2. 首页/资料 → 建立课程 → 新建 Markdown 笔记 → 输入内容并保存 → 选择封面 → 重启检查。
3. 导入自有测试 PDF → 阅读、批注 → 页面文字提取与校对 → 关键词搜索与来源页跳转。
4. 课程复习 → 手动题卡 → 自测反馈 → 返回课程查看记录。AI 生成只是可选来源。
5. 外观与数据 → 备份与附近传递 → 导出学习备份 → 选择文件恢复为副本，检查附件可读。
6. AI 设置分为自配 API 与云端目录；云端目录只预览 Seed/Qwen/DeepSeek/GLM，明确未开放，不作为可用云服务宣传。自配接入新建空密钥、未授权草稿，核对填写后单独授权。确需提供审核测试方式时，只在 AGC 的受控审核资料中提供经服务商允许且限额的方案，禁止公开 Key。
7. 附近传递使用同签名版本、同帐号可信组网设备，主动连接、选设备与课程、核对接收数量后导入副本；拒绝设备权限时仍可使用文件备份。没有异地自动云同步。
