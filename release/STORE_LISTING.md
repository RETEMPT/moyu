# 墨语应用市场资料草稿

对应候选：1.0.3（1001003），统一手机与 Pad。正式截图、发布者及最终类别需在 AGC 核对；本页不代表已上架。

## 名称与简介

名称：墨语

一句话简介：整理课程资料，阅读批注，题卡自测与复习。

## 应用介绍

墨语是一款面向校园学习的本地资料与复习工作台。把课程笔记、PDF 与图片文字整理到同一个资料库，从原文阅读到题卡自测形成连续的学习流程。

- 课程整理：建立课程分类，编辑 Markdown 笔记，选择封面、标签与双向链接。
- 阅读与校对：阅读 PDF，保留笔迹和批注，提取页面文字并人工校对；支持的设备可使用系统 OCR。
- 自测复习：手动建立题卡，查看资料来源，记录自测反馈与复习进度。
- 本地助手：关键词搜索原文、摘录要点、提取任务候选与资料概览，结果附原文出处；不要求注册帐号或填写 Key。
- 资料迁移：导出课程学习备份，恢复时保留原资料并导入副本。附近可信设备传递为试用功能，依赖系统能力与组网条件。
- 手写笔：笔与触控分流、压感笔迹、双指缩放、撤销/重做；在支持对应事件的设备上可用笔身双击切换橡皮擦、轻捏呼出工具。

手机与 Pad 复用同一套资料结构与图标，按窗口宽度切换布局。手机保留首页、资料、墨客、待办、图谱五项导航。学习资料保存在本机，首次资料库为空；卸载前请导出备份。助手使用规则与关键词摘录，不内置生成式大模型，PDF 文字需先提取并校对。

## 版本说明

默认离线助手，可授权自配 API；本地与模型输出统一排版。独立设置保留本地备份，云服务/云备份未开放。统一文档封面、图标标签与居中菜单；文档默认只读，下滑收缩顶栏，无改动直接退出。优化白板左右平移和 PDF 持久导入，手动提供真实阅读测试文件；日历新增农历、节日及核对过的 2026 年休/班。

## 审核操作说明

1. 首次启动阅读说明，可选择“暂不同意，离线使用”；不要求登录或填写 Key。
2. 首页/资料 → 建立课程 → 新建 Markdown 笔记 → 输入内容并保存 → 选择封面 → 重启检查。
3. 导入自有测试 PDF → 阅读、批注 → 页面文字提取与校对 → 关键词搜索与来源页跳转。
4. 课程复习 → 手动题卡 → 自测反馈 → 返回课程查看记录。
5. 设置 → 资料库 → 本地备份 → 导出学习备份 → 选择文件恢复为副本，检查附件可读。云备份标记未开放。
6. 墨客 → ＋ 引用刚创建的文字笔记 → 提取要点/整理待办 → 核对出处；输入课程关键词查询原文。无 Key、断网可体验本地助手；设置另提供可选授权 API，云 AI 不可启用。
7. 附近传递使用同签名版本、同帐号可信组网设备，主动连接、选设备与课程、核对接收数量后导入副本；拒绝设备权限时仍可使用文件备份。没有异地自动云同步。
