# 商店提交文案

应用名称：墨语

一句话介绍：把课程资料整理成可查、可写、可复习的本地笔记。

## 功能介绍

墨语支持手机和平板上的课程资料管理、Markdown 笔记、PDF 阅读批注、手写记录、双链图谱、日历待办与课程自测。图片和页面文字识别后可先校对，再通过本地规则排版，保留原文供核对。支持手动题卡、本地文件备份和恢复。

## 1.0.5 更新

修复图谱新建空主题不显示的问题，新建主题与项目等待保存成功后再完成操作；优化手机输入、操作区与平板宽窗口布局，统一首次隐私声明流程。

## 审核操作路径

1. 干净安装，检查平台托管的首次隐私声明；进入首页后无第二个自建声明。
2. 首页新建笔记，保存并重启核对。
3. 图谱新建主题，核对空主题计数为 0，切换页面和重启后仍存在。
4. 首页“提取内容”粘贴一份含标题、段落和明确待办的文字，检查预览、原文和保存结果。
5. 导入 PDF，阅读、翻页、批注、保存并重新打开；在更多菜单打开随堂稿纸。
6. 课程复习创建手动题卡，记录一次自测反馈；设置导出和恢复资料备份。

截图与录屏应来自本次实际签名安装包，覆盖手机和平板。发布主体、客服和隐私链接在 app-market.json 中填写。
