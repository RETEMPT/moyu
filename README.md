# 墨语

HarmonyOS 手机与平板上的本地资料库与笔记工具。

[下载 1.1.0](https://github.com/RETEMPT/moyu/releases/tag/v1.1.0) · [使用说明](docs/USER_GUIDE.md) · [隐私说明](docs/PRIVACY.md)

- 阅读 PDF、Markdown、TXT 与图片，支持顶栏标签拖放分屏
- 手写批注、随堂稿纸、区域/整笔橡皮
- 项目分类、双链图谱、搜索、回收站
- 待办、复习题卡、本地文字识别
- 资料备份与快传

资料保存在本地，无需账号，不联网。

> 商店版本为离线版，AI 功能显示"即将上线"，后续版本开放。

## 技术栈

- 语言：ArkTS
- UI：HarmonyOS Declarative UI
- 最低 API：24
- PDF：Mozilla PDF.js（离线）
- 存储：Preferences + 应用内文件目录
