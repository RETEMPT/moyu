# 墨语

HarmonyOS 手机与平板上的本地课程资料和笔记应用。

[下载与版本记录](https://github.com/RETEMPT/moyu/releases) · [使用说明](docs/USER_GUIDE.md) · [隐私说明](docs/PRIVACY.md)

[文档总览](docs/README.md) · [开发指南](docs/DEVELOPMENT_GUIDE.md) · [代码规范](docs/CODE_STANDARDS.md)

- 阅读 PDF、Markdown、TXT 与图片，也可将 DOCX、PPTX 导入为可检索的 Markdown 文字版。多份资料可通过顶栏标签拖放分屏。
- 手写批注、随堂稿纸、撤销重做，以及区域／整笔橡皮。
- 项目分类、资料菜单、回收站、搜索、双链与图谱。
- 待办、复习题卡，以及从一份文件识别文字、校对并保存为 Markdown。
- 文件备份恢复及主动系统分享。

资料保存在本机，无需账号。当前版本不提供自动云同步。

## 1.2.1 更新与能力边界

当前源码版本为 1.2.1（1020100）。本轮更新了资料库、文件导入、白板批注和学习助手联调。完整能力见[产品范围](PRODUCT_SCOPE.md)。

| 内容 | 当前状态 |
| --- | --- |
| 文档导入与阅读 | 通过系统授权读取文件，PDF 分块复制并显示进度。资料库支持书架、列表和时间流，返回时恢复筛选。 |
| 文字识别与批注 | 选择一份文件，预览、编辑并保存 Markdown。白板和阅读器使用可收起的深色笔具栏。 |
| 本地复习 | 按资料查看阅读与自测概况，筛选待巩固题，到期弱项优先，编辑题卡保留复习安排 |
| [云模型与 Agent 工具](cloud/ai/README.md) | 电脑端支持 DeepSeek、千问百炼、OpenAI 与兼容端点，提供可选 MCP 工具 |
| [离线学习结果](docs/LEARNING_INTEGRATION.md) | 原文导出、结果预览、引文回跳和题卡人工采纳 |

发布候选仍需构建、签名和设备验证。学习助手的模拟器联调仅面向显式开启的 Debug 构建。电脑端工具使用独立明文工作区，鸿蒙端可通过所选文件导入学习结果。[联调说明](cloud/ai/README.md)

### StudyDemo 模拟器联调

启动电脑端网关后，运行 `deploy_hap.bat -StudyDemo` 构建并安装调试包。AI 墨客支持会话工作区、附件预览、连续追问、可展开的工具轨迹，以及按文件名和页码或行号打开原文。可选择思考深度，DeepSeek Flash 的普通对话可以按需开启联网。 [配对与使用说明](cloud/ai/README.md)

## 发展方向（规划）

墨语计划将公开资料发现、私人资料管理和云AI学习辅助逐步融入研读过程，让资料获取、批注、整理和复习之间保持联系。未来的云AI将围绕摘要、带出处问答和题卡候选等任务提供辅助，各项云服务可按需选择。团队托管云AI、收费云盘和公开资料库目前均为规划，尚未实现或开放购买。

这些方向将随产品演进逐步推进，与本地阅读、书写和复习衔接。详见[商业价值](docs/BUSINESS_PLAN.md)、[云AI服务方向](docs/CLOUD_AI_BUSINESS.md)、[产品特点](docs/INNOVATION.md)及[未来开发方向](docs/ROADMAP.md)。

## 开发与许可证

Release 附件为手机和平板共用的正式模式构建，不包含调试示例或测试资源。附件名标注 `unsigned` 时尚未配置发布签名，须签名后安装；升级时应保持签名一致，卸载前请先备份资料。

Mozilla PDF.js 离线引擎采用 Apache-2.0 许可证，原许可证保留在其资源目录中。
