# 新建、AI 引用、伴读与笔控验收记录

方案及调研来源见 [实施方案](UX_REFINEMENT_PLAN_2026-10-09.md)，操作说明见 [使用指引](USER_GUIDE.md)。

## 已实现

- 新建内容展示图标、类型名称和用途；标题输入不再聚焦清空。创建前可选项目、填写独立主题标签，成功写入后打开笔记，失败保留表单。项目菜单的参考资料改为真实导入，白板不再命名为导图。
- AI 加号、更多、模型菜单直接绑定原生 Button，并由系统处理打开、选择、外部关闭及返回，避免原有自定义按钮点击和菜单显隐竞争。加号按资料、离线任务、模型任务分组；未配置/授权/选用时模型任务显示灰色。右上角新建对话位于更多左侧；移除输入区“本地助手 · 离线”状态文案。
- 更多提供搜索引用、设置、复制对话、重新回答、撤回和删除。引用选择区支持标题、项目、标签及正文关键词，可连续添加；最多显示 40 项，已选和回收站项不再列出。无引用时仍可本地检索资料库。PDF 正文仅检索校对索引，不把导入说明当内容。
- 白板、稿纸、PDF 共用笔粗滑杆与范围，各工具独立保留大小和颜色。参数改变先完成当前笔触，不切回普通笔。顶栏和浮球动态显示主文档当前工具，工具图标和小字共同高亮；笔快捷橡皮恢复此前墨水工具。PDF 橡皮大小按页面比例映射，整条笔迹删除可撤销。
- 设置使用指引内包含 DeepSeek / 百炼步骤图解、配置字段示意、官方密钥与首次调用入口、授权和连接故障说明。示意图不包含真实密钥；仅在用户点击时打开浏览器。
- 伴读采用紧凑文档标题、明确文字范围、轻量正文和底部输入。PDF 可选本页或全部已校对页，没有文字时提供提取入口。当前文档保存不打断会话；切换文档/本页范围使旧请求失效。追问带有效历史，答复标记实际使用范围。离线任务切换的重复点击及晚到回调受到保护。

## 设备验收仍需完成

当前没有可用 HDC 设备。发布/市场送审前在手机和 Pad 使用同一候选包逐项记录：

1. 主页新建：切换类型、选择空项目/未分类、多个标签，输入后聚焦不清空；模拟保存失败后重试。
2. AI：空会话和有历史时分别打开加号/更多；键盘弹出、旋转、窄窗口和分栏下检查菜单及资料选择区；系统返回先关闭菜单/选择区。
3. 离线：无 Key 搜索标题和正文、选择引用、摘录和明示待办；灰色生成任务不可执行。配置并授权模型后选用、提问、停止、失败重试；真实服务测试不在自动回归中调用。
4. PDF：分别导入阅读和快照 PDF，翻页、缩放、文字层提取、扫描 OCR 校对、缺原件重关联及保存失败；错误页禁止绘制。伴读本页/校对页范围与结果来源一致。
5. 批注：普通笔/荧光/橡皮滑动大小，来回切换，图标、顶栏及实际效果一致；撤销重做、快捷双击、笔接管手指、取消触点和恢复只读。白板与稿纸执行同样步骤。
6. 伴读：追问使用历史，保存批注不打断；切换文档/页时旧答复不会落入新范围；确认清空及关闭分屏。伴读仍为进程内缓存，不承诺重启恢复。
7. 图解：手机/Pad 明暗主题下检查字距和示意字段换行，官方链接可打开，配置修改离开有未保存保护。

个人主体信息、隐私 URL、正式签名和同包真机材料仍是上架前置阻塞项，不随 UI 与服务回归通过而自动完成。
