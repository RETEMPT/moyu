# FlowMind（墨语）v1.0.2

本次更新解决无 API 使用、首次样例内容与新建笔记问题，并重绘图标、精简工具栏、接入鸿蒙原生菜单和分享。团队无需维护云服务；手机与 Pad 共用一个版本。

## 更新内容

- **无 API 可用**：release 默认且仅提供本地助手，支持中文原文检索、要点摘录、待办候选与资料概览，带真实行号或 PDF 页码。无需账号、Key 或网络；生成式模型只留在 debug，发布包同时阻断模型网络调用。
- **空库与新建修复**：首次不注入演示资料；笔记、项目和日记按实际模板保存。保存成功后再打开阅读器，空白文字笔记直接编辑，手写笔记从首页一键进入。失败保留输入，避免新建无效和内容丢失。
- **图标与布局**：重绘浅/深色应用图标及 55 个工具资源。首页、阅读器、格式和笔工具采用图标按钮，提供原生提示和无障碍名称；主要触控区 44vp，窄工具栏支持横向滚动。颜色和笔粗按需展开，保留必要的导航、状态及确认文字。
- **笔控与响应**：区分笔、手指和手掌输入，读取压力/历史点，增量绘制平滑曲线；完善缩放、平移、撤销/重做及分屏焦点。Penkit 接入笔身双击切换橡皮擦、轻捏工具；debug 远程请求支持超时、停止及忽略迟到响应。
- **鸿蒙原生操作**：文档更多菜单使用 ArkUI 原生菜单，Share Kit 分享当前文字或原 PDF，键盘 Ctrl+F 搜索，主题跟随系统，编辑器恢复键盘避让设置。原 PDF 分享不包含应用内笔迹。
- **使用指引**：应用内和仓库说明覆盖图标、新建、离线助手、笔控、分享、备份及审核复测；移除未开放云端目录与重复宣传文字。

## 下载与安装

发行页面：[v1.0.2](https://github.com/RETEMPT/moyu/releases/tag/v1.0.2)。GitHub 同时提供标签源码 ZIP/TAR。

| 附件 | 内容 |
| --- | --- |
| `FlowMind-1.0.2-HarmonyOS-unsigned.zip` | release APP、从最终 APP 提取的 HAP、安装说明、内部校验值 |
| `BUILD_INFO.json` | 源码提交、实际包元数据、SDK、验证范围、构建文件摘要与 CI 链接 |
| `SHA256SUMS.txt` | GitHub 附件与包内文件的 SHA-256 校验值 |

包名 `com.retempt.flowmind`，版本 `1.0.2` / `1001002`。兼容 SDK `6.1.1(24)`，目标 SDK `26.0.0`。附件为**未签名开发构建**，不直接作为应用市场安装包；真机安装需要适用签名。检出标签后在 DevEco Studio 配置设备签名，再构建：

```powershell
.\build_hap.bat -StudioDir "<DevEco Studio 安装目录>" -BuildMode release -AppPackage -Clean
```

升级保持包名和签名一致，先备份学习资料；签名不一致时不要直接卸载覆盖。

## 验证与边界

201 项服务/工作流检查、11 项发布规则检查、生成资源校验、GitHub CI 与干净 release APP/HAP 构建通过。实际包的身份、版本、设备类型、权限、备份配置和 release 模式完成检查；构建保留既有弃用告警。具体源码提交、时间、摘要及 CI 链接记录于下载附件 `BUILD_INFO.json`。

本地助手提供检索和规则整理，不是端侧大模型。服务检查使用平台替身，尚无星闪笔、系统分享接收方、双设备传递、升级和系统密钥库的本次真机验收，因此不承诺与华为笔记相同的延迟或防误触表现。未提供团队云盘、小艺接入或自动云同步。

卸载和换机前使用“外观与数据 → 备份与附近传递”导出资料，恢复导入副本。备份为明文，不含模型密钥/配置、对话、待办/日期备忘和回收站；系统整包备份保持关闭。

正式上架仍需发布者资料、托管隐私网址、资质及 AGC 核对、正式签名、对应包的真机报告和截图；这些缺项由严格市场检查阻断。
