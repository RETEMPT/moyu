# 墨语 v1.0.4

PDF 导入后保存应用内副本；单页阅读支持上下滑动翻页，点笔后可以直接批注。阅读界面缩成单行顶栏和左下角页码块，点击页码在旁边输入目标页，手机与 Pad 使用同一套操作。

- 保留外部原文件，重启和覆盖安装后按副本文件名恢复路径；旧版可读取的引用自动迁移，批注保留。资料备份携带原 PDF 和笔迹。
- 整页按正文可用宽高适配，连续阅读缩小页间距与留白；放大后在页内平移。批注时选择“拖动页面”再翻页，避免把书写当作滑动。
- 修复切换工具时同一页被错误标记为未加载、无法落笔的问题。默认允许手指与鼠标书写，笔设置仍可切换为仅手写笔。
- 收藏、伴读、稿纸和阅读方式收进“更多”，沉浸模式释放顶栏占位；手机的笔工具可横滑，伴读和稿纸使用全宽抽屉。
- 调试构建自动加入两页测试 PDF；发布构建排除测试 PDF、页面预览图片和导入入口。缺少 PDFKit 的模拟器只在调试版显示与内置原件一致的预览；真实 PDF 解析、渲染和提取需要支持 PDFKit 的设备。
- 同时包含设置分组与主题、菜单和工具选中反馈、对话记录、智能提取和 Marker 结果导入等此前完成的工作区改进。

包名 `com.retempt.flowmind`，版本 `1.0.4` / `1001004`，手机与 Pad 共用。兼容 SDK `6.1.1(24)`，目标 SDK `26.0.0`。附件是**未签名开发构建**；安装到设备需要在 DevEco Studio 配置适用签名，再从标签构建。升级应保持包名和签名一致，保留应用数据；卸载前先导出本地资料。

## 验证范围

366 项工作流、47 项 PDF 生命周期、11 项编译后界面交互和 13 项发布规则检查通过；debug HAP 与干净 release APP 构建通过，发布包核对版本、设备、权限和调试资源排除。

在 MatePad 模拟器实测整页双向翻页、点笔落墨、批注重启恢复、紧凑页码弹出框。另用同一 ArkUI 组件的 360×780 vp 临时视口检查手机布局、整页翻页与跳页框；临时视口和诊断日志不进入提交。手机系统镜像未安装，未完成手机或 Pad 真机及星闪笔验收。服务测试使用平台替身，模拟器测试使用调试 PDF 预览，不替代真实 PDFKit 设备验证。

具体提交、构建元数据、校验值和 CI 链接见附件 `BUILD_INFO.json`。正式应用市场签名及发布资料尚未配置，团队云服务仍未开放。
