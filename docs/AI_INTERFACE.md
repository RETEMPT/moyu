# AI 界面与接入边界

更新：2026-10-07。属于 GitHub v1.0.1，尚未发布至应用市场。

## 更少的常驻控件

聊天页保留当前模型、新对话、AI 设置与四种研读模式。手机的资料入口集中在输入框旁的加号菜单；Pad 另保留来源快捷入口。两端复用现有 SVG 与主题色，手机五项底栏不变。

输入框支持换行，“发送”和“停止”共用操作位置。引用标签横向滚动，各自可移除；生成中不更换资料。加号菜单提供识别、引用、导入和撤回上一轮消息，移除了重复的模型入口与未实际生效的通用思考滑块。支持的兼容推理模型可在模型菜单调整 reasoning_effort，其他模型不显示该控件。

默认展示四个学习快捷场景，另外两个在“更多用法”。选择场景只填入问题，由用户补充并发送。方案统一呈现为建议操作，执行前确认；撤回消息会等待保存，失败保留原对话，不撤销已经创建的笔记或待办。

## 两种接入入口

**自配 API**：选择档案后填写名称、服务地址、密钥和模型 ID。连接页直接显示可选发送授权，输出与检索、工具权限、协议和档案管理折叠在“高级”。草稿切换与关闭提示沿用原有行为。

**云端 AI**：本机静态目录，明确标注“尚未开放”。浏览、筛选和选择仅用于预览，不接后台、不计费、不启用云端档案。“用自己的 API 接入”会新建无密钥、未授权的自配草稿，保留原档案及其未保存输入。必须核对服务、填写 Key、单独授权后才允许测试或问答。

目录显示 Seed、Qwen、DeepSeek、GLM 四个系列。模板是文本兼容 API 示例，不等于已经完成各厂商帐号的真实连通或支持其所有图像、音频、搜索和编程订阅能力。用户可修改地址与模型 ID，实际可用范围、地域、费用和数据规则以服务商控制台为准；不预置价格或能力排名。

方舟和智谱模板使用完整聊天端点，避免兼容层误补 `/v1`。百炼示例采用北京地域，需按业务空间调整。编程订阅的专属 Key/端点不作为普通聊天模板。Ollama 模板仅连接设备本机的无密钥服务；填写 API 不意味着应用本身内置推理引擎。

## 验证与待验收

当前 170 项服务与 11 项发布门槛测试通过。新增服务测试覆盖目录不可用状态、模板隔离、新草稿的空密钥与未授权状态、各模板实际请求路径、无密钥本机请求，以及消息撤回的保存失败和已删除会话保护；使用平台替身，不请求真实厂商服务。ArkTS 与 release APP 构建检查控件及资源兼容。

仍须双真机检查：模型筛选/预览不改变当前服务，切换后草稿与授权状态正确；手机软键盘、长标签、大字体、横竖屏/Pad 分屏、减少动态效果与读屏；七个模板按拥有权限的帐号逐项连通，验证超时、停止与失败结果。没有测量帧率或收费服务可用性，不能将编译通过记作完整交互验收。
