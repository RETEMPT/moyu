# 助手界面与接入边界

v1.0.3 默认本地助手，无需账号、Key 或网络；设置允许用户授权自配 API，云 AI 尚未开放。使用步骤见 [指引](USER_GUIDE.md)。

## 操作与输出

墨客左上角为对话记录图标，打开后记录独占侧栏，支持搜索、时间分组和置顶；再次点击或外点恢复原侧栏。输入框旁 ＋ 是原生锚定菜单，集中资料引用、导入、识别和任务；模型选择独立，新建对话位于右上角更多左边，更多承载会话操作。动态菜单使用显式状态和具名 Builder。引用标签横向滚动；发送和停止使用同一位置。删除、清空与撤回先确认，读取失败先重试，已删除会话拒绝迟到回答与旧快照。

本地与模型回答复用 `AssistantText`：按源文顺序呈现标题、列表、引用、表格、代码及多段公式，流式更新合并到 80ms。长表格可横向浏览，代码和公式可复制；行内粗体、斜体、删除线与代码保留。公式块显示可复制源文，未接入完整 LaTeX 图形排版引擎。

本地快捷场景包括提取要点、整理待办、搜索原文和资料概览。它使用原文与规则，不是端侧大模型；任务候选不自动写入。空库或无匹配给出新建、导入、校对或修改关键词的步骤。出处使用实际 Markdown 行号或 PDF 页码。手写笔迹不能直接检索，PDF 需先提取并校对文字。

## 设置与模型

“设置 → AI 与模型”提供本地、自配 API、云 AI 三项；云项显示未开放且不可启用。默认模式存储独立于 HUKS，密钥库失败不阻塞本地路径；存在旧 API 档案也不会自动切换默认来源。

自配 API 在 debug 和 release 都可使用：填写 HTTPS 地址、实际模型 ID 和密钥，确认该地址/协议的数据发送授权后测试、保存，再选择该模式。可从 Seed、Qwen、DeepSeek、GLM 目录主动创建新草稿；旧档案和未保存输入保留，模板不携带密钥、授权或自动启用工具。新安装仍默认本地，不自动选择厂商或改写已有模型 ID。由 `RemoteAiPolicy` 核对授权和安全地址。Key 使用 HUKS 加密保存，主动请求才发送选择的资料；团队不运营中转或推理服务。

目录是 2026-10-09 核对的配置参考，开通状态、地域与型号以控制台为准。Seed 的实际模型/接入点 ID 需手动填写；Qwen 北京兼容地址可调整为业务空间专属域名。参考：[Seed](https://docs.volcengine.com/docs/ark/model-list?lang=zh)、[Qwen](https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope)、[DeepSeek](https://api-docs.deepseek.com/)、[GLM](https://docs.bigmodel.cn/api-reference/模型-api/对话补全)。

保留原 L1/L2/L3、工具调用、题卡和 AI 排版。高级参数、向量检索、工具权限与档案管理按需展开。兼容推理模型可调整 reasoning_effort，其他协议不显示该控件。写操作逐次确认并等待保存，不能仅凭请求发出就提示成功。

内置 Function Calling 共 15 项工具，支持资料分页查询、原文/大纲/待办读取，以及确认后新建、重命名、修改文字正文、分类、标签、双链、收藏/置顶和待办完成状态。正文更新必须匹配读取版本，PDF/手写原件和正在编辑的正文禁止覆盖。实际工具链仅在支持工具的 OpenAI 兼容/自定义流式模型及相应权限下启用；不代表外部 MCP 或任意文件系统管理。智能提取增加独立 AI 整理开关、本机 PDF 提取及 Marker Markdown 结果导入，范围见 [端侧评估](MARKER_HARMONY_REVIEW_2026-10-09.md)。

流式首响应上限 45 秒、事件间隔 30 秒、总时长 180 秒；非流式 60 秒，向量检索超过 12 秒回退关键词。停止关闭请求并忽略迟到输出，保留已接收文字供核对。墨客的外部导入共用资料库持久化流程，保存成功后才添加引用；切换会话时不挂到新会话。

## 验证范围

截至 2026-10-09，354 项工作流、30 项 PDF 专项、11 项发布规则、6 项编译后交互回归和干净 release APP 构建通过。包含本地/授权边界、取消与会话读取/删除、导入资源清理、保存失败回滚、正文版本保护以及菜单转换与工具选中订阅。平台替身不请求真实厂商服务，不代表真机 UI 或 Marker 模型部署验收。

仍需手机/Pad 检查无 Key 和自配 API 两条路径、小屏键盘、长表格、最大字体、分屏、旋转、读屏与系统密钥库。尚无实际帧率、端到端响应或笔延迟测量。
