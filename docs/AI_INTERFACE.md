# 助手界面与接入边界

更新：2026-10-08。当前工作区按审核反馈整改；release 默认且仅提供本地助手。使用步骤见 [使用指引](USER_GUIDE.md)，问题对应方案见 [审核整改](REVIEW_FIXES_2026-10-08.md)。

## 更少的常驻控件

聊天页保留“本地助手 · 离线”、新对话、助手设置与资料引用。手机的资料入口集中在输入框旁的加号菜单；Pad 另保留来源入口。“墨客”发布版不显示 L1/L2/L3 模型层级或远程配置。两端复用现有 SVG 与主题色，手机五项底栏不变。

输入框支持换行，“发送”和“停止”共用位置。引用标签横向滚动，可移除；处理时不更换资料。加号菜单提供识别、引用、导入和撤回上一轮消息。引用可回到 Markdown 原文行号或 PDF 的真实页码，扫描 PDF 要先提取并校对文字。

本地快捷场景为提取要点、整理待办、搜索原文、资料概览。提取使用原文与规则，不是端侧大模型；手写笔迹尚不能直接检索。没有资料或匹配时给出新建、导入、校对或修改检索词的步骤。任务候选不自动写入。撤回消息等待保存，失败保留原对话，不撤销已创建的笔记或待办。

## 发布与开发模式

`RuntimeCapabilities` 使用 `BuildProfile.DEBUG`：release 不显示远程模型、AI 排版或模型题卡入口，`RemoteAiPolicy` 同时阻止聊天、连接测试及向量 HTTP 请求。即使本机有旧远程配置也只使用本地助手；本地模式的设置独立于模型密钥库，密钥不可读不会阻塞离线路径。

debug 提供“本地助手 / 自配模型”。自配服务填写名称、地址、实际模型 ID 和密钥，确认该服务的数据发送授权后测试与保存；高级参数、检索、协议、工具权限及档案管理按需展开。模型默认 ID 和远程地址为空，不预设厂商型号；本机服务模板也要求填写已安装的模型 ID。原云端目录移出生产模块，应用不提供团队运营的服务。

开发模式的 L1/L2/L3、工具调用与向量检索仍使用用户服务；写入逐次确认并等待保存，不能凭请求发出就提示完成。兼容推理模型可调整 reasoning_effort，其他协议不显示该控件。费用、数据规则与可用型号由提供方决定。

流式首响应上限 45 秒、事件间隔 30 秒、总时长 180 秒；非流式上限 60 秒，向量检索超过 12 秒回到关键词结果。停止立即结束调用，不接收晚到输出；错误保留已经接收的文字，可重试或切换本地助手，不自动修改模型 ID。

## 验证与待验收

当前 196 项工作流与 11 项发布门槛测试通过，debug HAP / release APP 编译通过。新增离线空库、中文检索、引用范围、实际行号/PDF 页码、任务提取、取消、模式保存失败、旧配置强制本地与 release 全协议网络阻断测试；使用系统替身，不请求真实厂商服务。

仍须双真机检查：release 断网/无 Key 完成助手与学习路径，小屏键盘、长标签、大字体、横竖屏/Pad 分屏、减少动态效果与读屏；debug 自配服务另测连通、授权、超时及停止。没有测量帧率或硬件落笔延迟，不能将编译通过记作完整交互验收。
