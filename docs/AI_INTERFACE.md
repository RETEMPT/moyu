# 助手界面与接入边界

v1.0.3 默认本地助手，无需账号、Key 或网络；设置允许用户授权自配 API，云 AI 尚未开放。使用步骤见 [指引](USER_GUIDE.md)。

## 操作与输出

墨客顶行只显示名称和当前来源。新对话、引用、导入、识别、AI 配置、模型切换及历史操作集中在输入框旁的居中 ＋ 面板，动作配图标与明确名称。引用标签横向滚动；发送和停止使用同一位置。删除、清空与撤回先确认，失败保留原记录；已删除会话拒绝迟到回答与旧快照。

本地与模型回答复用 `AssistantText`：按源文顺序呈现标题、列表、引用、表格、代码及多段公式，流式更新合并到 80ms。长表格可横向浏览，代码和公式可复制；行内粗体、斜体、删除线与代码保留。公式块显示可复制源文，未接入完整 LaTeX 图形排版引擎。

本地快捷场景包括提取要点、整理待办、搜索原文和资料概览。它使用原文与规则，不是端侧大模型；任务候选不自动写入。空库或无匹配给出新建、导入、校对或修改关键词的步骤。出处使用实际 Markdown 行号或 PDF 页码。手写笔迹不能直接检索，PDF 需先提取并校对文字。

## 设置与模型

“设置 → AI 配置”提供本地、自配 API、云 AI 三项；云项显示未开放且不可启用。默认模式存储独立于 HUKS，密钥库失败不阻塞本地路径；存在旧 API 档案也不会自动切换默认来源。

自配 API 在 debug 和 release 都可使用：填写 HTTPS 地址、实际模型 ID 和密钥，确认该地址/协议的数据发送授权后测试、保存，再选择该模式。由 `RemoteAiPolicy` 核对授权和安全地址，不预设厂商模型、不自动改写 ID。Key 使用 HUKS 加密保存，主动请求才发送选择的资料；团队不运营中转或推理服务。

保留原 L1/L2/L3、工具调用、题卡和 AI 排版。高级参数、向量检索、工具权限与档案管理按需展开。兼容推理模型可调整 reasoning_effort，其他协议不显示该控件。写操作逐次确认并等待保存，不能仅凭请求发出就提示成功。

流式首响应上限 45 秒、事件间隔 30 秒、总时长 180 秒；非流式 60 秒，向量检索超过 12 秒回退关键词。停止关闭请求并忽略迟到输出，保留已接收文字供核对。墨客的外部导入共用资料库持久化流程，保存成功后才添加引用；切换会话时不挂到新会话。

## 验证范围

227 项工作流、11 项发布规则和干净 release APP 构建通过，包括本地/授权边界、原文出处、文本保留、取消与会话删除、保存/导入失败保护。平台替身不请求真实厂商服务，不代表真机 UI 验收。

仍需手机/Pad 检查无 Key 和自配 API 两条路径、小屏键盘、长表格、最大字体、分屏、旋转、读屏与系统密钥库。尚无实际帧率、端到端响应或笔延迟测量。
