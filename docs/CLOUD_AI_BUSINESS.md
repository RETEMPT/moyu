# 云AI学习服务发展方向

未来的云AI服务将围绕用户正在研读的资料，提供理解、整理和复习辅助。它以团队托管的方式降低使用门槛，让用户能够直接选择任务，同时保留自带模型服务的扩展选择。

## 学习场景与价值

| 方向 | 使用场景 | 预期价值 |
| --- | --- | --- |
| 课程资料摘要 | 初次阅读课件或章节时建立整体认识 | 形成清晰提纲，保留关键概念和原文出处 |
| 基于资料的问答 | 对照笔记和课本理解一个问题 | 给出有资料依据的解释，便于继续核对 |
| 复习卡候选 | 把已理解的内容整理为自测材料 | 减少重复录入，将问题、答案和来源联系起来 |
| 结构化整理 | 对术语、观点或章节进行比较 | 形成可编辑的提纲、术语表和对照表 |
| 多资料研读 | 从多份授权资料中梳理同一主题 | 帮助发现关联、差异和需要继续阅读的部分 |

这些方向将与本地工作台结合：选择资料或片段，查看整理结果与引用，修改并采纳，再将成果保存为笔记或题卡。

## 产品设计

**围绕原文组织结果。** 回答和摘要保留资料身份、版本与引用范围。资料发生变化时，提示重新核对；原文没有覆盖的问题，明确表达信息不足。

**保留使用者的判断。** 云AI生成的内容作为独立草稿呈现，用户可以编辑、放弃或采纳。它不改写原件，也不直接替代用户的笔记和答案。

**让任务可以继续。** 长任务提供状态、取消和失败恢复；已产生的本地记录保留，网络变化不阻断基础阅读。

**明确资料范围。** 用户在发送前选择内容并了解处理服务。私人资料、公开资料和加密副本采用各自的数据边界，详见[云服务技术设计](CLOUD_AI_DESIGN.md)。

## 可持续的服务模式

云AI可以作为独立的可选服务，也可以与私人存储组合提供。服务权益围绕任务范围、处理用量和支持内容设计，用户可以在使用前了解额度与消耗。

- 学习服务：覆盖日常摘要、资料问答和复习整理。
- 按需扩展：支持集中复习、批量整理等阶段性需求。
- 机构服务：围绕获得授权的课程与专业资料，提供独立资料域和技术支持。
- 自带服务：允许有需要的用户接入自己的推理服务，与托管服务分别管理。

具体价格与额度将结合真实任务成本、使用反馈和服务质量确定。基础本地功能保持独立，用户可以按自己的需求选择云端能力。

## 发展重点

先做好单份资料的摘要与引用核对，再拓展问答、题卡和多资料研读。评估重点包括结果是否有原文支持、人工修正的负担、采纳后的可用性，以及任务耗时与资源消耗。

后续可与[公开资料库及私人云盘](WEB_PLATFORM_PLAN.md)衔接，在用户授权范围内建立可复用的资料索引。云AI的发展始终围绕学习资料的理解与积累，完整方向见[未来开发方向](ROADMAP.md)。
