# 墨语开发指南

基线：1.1.1，HarmonyOS 手机／平板原生应用。接手前阅读[代码规范](CODE_STANDARDS.md)和[架构](ARCHITECTURE.md)。

## 环境与构建

工程使用ArkTS／ArkUI、Hvigor、HarmonyOS RDB。`oh-package.json5`为modelVersion 26.0.0，目标SDK 26.0.0，兼容6.1.1（API 24）。

使用匹配 SDK 的 DevEco Studio，在本机配置 `DEVECO_STUDIO_HOME`，由工程依赖锁定文件恢复依赖。

```powershell
# 构建 release APP 和 HAP
.\build_hap.bat -BuildMode release -AppPackage -Clean

# 安装到已连接设备
.\deploy_hap.bat
```

构建产物为 `build/outputs/default/` 下的 APP 与 `entry/build/default/outputs/default/` 下的 HAP；`unsigned`表示没有发布签名，不能当作可直接安装的正式包。

构建与设备运行是独立步骤，不把自动编译当作真实设备交互验证。

## 关键用例如何走通

**导入**：系统选择器返回用户授权文件 → 原件复制到应用目录 → 解析及封面准备 → 在统一变更队列中基于最新资料提交 → 持久化成功后更新界面。最多 20 份顺序处理，批次可部分成功；失败不删除之前成功资料。

**编辑／批注**：工作台发出有类型的提交 → `ReaderCommitService` 读取最新资料 → `ReaderCommitPolicy` 按区域合并自身字段 → 正文／元数据保存 → 成功发布。退出等候在途保存；失败保留脏状态。正文文件与 RDB 不是联合事务，跨文件断电恢复仍需补齐。

**资料与项目回收**：`WorkspaceLifecycle` 生成计划 → 同一 RDB 事务保存资料、项目及两类回收记录 → 发布新状态。彻底删除先写 pending deletion 记录，再幂等清理文件；失败下次重试，不删除仍有引用的附件。

**OCR 与整理**：系统能力检测 → 页／图片文字识别 → 人工校对 → 规则结构化 → 原文和预览 → 用户选择待办 → 保存。PDF 提取每次 1–5 页，整理输入上限 12000 字；全部本地处理，不是云端生成。

**备份与分享**：明确选择资料 → 按允许字段组装 → TaskPool 编解码与校验 → 生成临时资料包 → 系统分享面板 → 接收方确认导入副本。当前上限为包 32 MB、单附件 16 MB；面板打开不等于送达。备份不包括日历待办和回收站。

## 数据与迁移

数据库 schema=2：资料／项目／回收站使用事务快照分片；待办、日期备忘、题卡与草稿使用同库领域表。旧 Preferences 经校验只读迁移并保留，不静默回退到旧副本。缺分片、目录损坏或未来 schema 拒绝写入，不能清空库来让新版本启动。

正文由 `AtomicTextFile` 临时写入、同步、关闭后替换；保存输入在异步前捕获。扩展资料字段时同步修改类型、快照复制、合并策略、持久化校验、备份白名单与恢复迁移。原件、批注和稿纸拥有不同字段；不能用整对象覆盖消除并发问题。

## 修改与验证顺序

1. 先看现有差异、调用方和失败路径，明确本次修改涉及的字段和系统资源。
2. 修改最小用例；业务规则留在纯策略，平台 API 留在服务适配。
3. 数据一致性、取消、迁移或新提交门槛需要对应行为验证；简单文案和可逆样式从简。
4. 应用源码变化后执行 release 构建，再在真实设备上验证对应功能。
5. 记录实际验证结果与未验收项；截图和设备反馈绑定同一候选版本。

## 常见故障

| 现象 | 处理 |
| --- | --- |
| 构建失败 | 确认 DevEco Studio 与 SDK 版本匹配，依赖由锁定文件恢复 |
| 编译通过、设备行为仍失败 | 区分纯策略、平台适配和真实设备差异，按实际失败路径复现 |
| PDF 慢、笔迹迟到或保存失败 | 保留原件与日志，定位后台任务／主线程绘制／任务代次／提交队列；先复现再修改，禁止清数据掩盖问题 |

## 本地学习增强

本地学习增强位于 `services/study/LearningProgressPolicy.ets` 和 `views/study/StudySheet.ets`，使用显式时钟与已提交资料／题卡，不新增库表。代码修改后仍需 release 编译和实际手机、平板的字号、键盘、布局和触控验收。云业务暂不开放，不预埋自动启用开关。

保存与迁移修改应记录版本、真实测试和未覆盖边界，不复用旧结果。新增网络与云处理时同步权限、隐私与凭据管理，让实现、用户说明和数据边界保持一致。
