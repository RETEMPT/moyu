# 墨语使用指引

适用版本：1.0.5，手机与平板。

## 收集与整理

首页选择文字笔记、手写笔记或导入资料。选择“提取内容”，可粘贴文字、选择图片或导入 PDF、Markdown、文字及 Marker 结果 JSON。图片先使用系统文字识别，再校对文字。

“保留原文”保持顺序与段落；“学习笔记”按明确标题和项目符号排版。需要时启用“合并图片断行”，并检查多栏阅读顺序、表格、公式、数字和日期。排版不会补充知识或猜测事实。原文与整理正文分开保留。

保存前检查标题、项目与正文，逐项选择需要创建的待办。已完成或带否定条件的行动不会作为待办；日期有歧义时保留原文供人工核对。长文请分段处理。

## 项目与图谱

在图谱点击“新建主题”，填写名称并确定。保存成功后切换主题，空主题显示为 0 篇；保存失败保留名称供重试。项目中加入资料后，图谱显示节点；点击两个节点可建立双链。主题和资料在重启后保留。

## 阅读与手写

文档默认只读，点击编辑或批注后修改。PDF 支持翻页、页面文字提取和原件重新关联。“更多文档操作”可打开随堂稿纸。原 PDF 分享不包含应用内笔迹，完整资料可用文件备份传递。

PDF 默认笔写、手指浏览；手机和白板可用手指书写。手掌图标切换手指书写，双指缩放与平移。双击与轻捏依赖手写笔和设备支持。保存完成后退出；失败时保留内容并重试。

## 自测、备份与隐私

课程复习中手动填写问题、参考答案和引用原文。先回忆再揭示答案，用“不会／模糊／掌握”安排下次复习。

设置中的“备份与传递”导出正文、原 PDF、封面、笔迹、已校对文字和题卡。恢复创建副本；备份是明文文件，请妥善保管。卸载前先备份，升级安装应保持签名一致。附近传递仅在主动连接时请求权限，接收需要确认。

隐私政策可在“设置 → 隐私与数据”查看。首次声明由平台托管配置提供。
