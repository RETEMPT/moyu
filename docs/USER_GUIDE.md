# 墨语使用指引

默认本地资料与离线助手，无需登录、API Key 或联网。左下角“设置”按工作空间、连接、安全与帮助分组，可搜索“主题”“OCR”“备份”等关键词。点击条目进入详情页，宽窗口可分栏查看；手机保留现有底栏。云服务、云 AI 和云备份未开放，本地备份可用。

## 外观与文字整理

“设置 → 外观与动效”可选择墨紫、黑白、浅蓝或蓝白，再独立选择跟随系统、浅色或深色。配色立即更新并保存，文档封面、纸色和笔迹保持原色。减少动态效果可关闭设置页面的转场动画。

“设置 → 文字识别与排版”或首页提取入口可选择图片，也可直接粘贴文字。系统 OCR 无需大模型密钥；不支持 OCR 的设备仍能粘贴并本地整理。识别后先校对姓名、数字、日期和公式。

“导入 PDF / 文字 / Marker 结果”可读取 PDF、Markdown、TXT 或 Marker Markdown 响应 JSON。选择文件后先保存到本机资料库“外部参考”：PDF 保留完整原件副本，文字与 Marker 响应保存为本地 Markdown 笔记，再从本机资料提取。提取失败或关闭窗口也会保留已经入库的资料。PDF 可填起止页，每次 1–5 页；先读文字层，空文字页尝试本机 OCR。文件最多 20 MB，文字文件最多 1 MB，本次文字最多 12000 字，较长资料分段提取。这里没有运行 Marker 模型或上传到 Marker 服务器；导入配套图片须另行保管。失败保留原输入，关闭后的提取结果不会追加。

- 保留原文：保留段落和原顺序，仅补文档标题。
- 学习笔记：将明确的独立标题、中文编号标题和项目符号整理成 Markdown 层级，不生成知识或概括原文。
- 合并图片断行：可主动开启，尝试连接普通正文，保留空段、列表、代码、表格和公式。多栏顺序与特殊换行需对照原文检查。

默认本地整理，无 Key 也可预览、编辑正文并保存。识别预览与阅读共用文本解析器；保存附上原文，待办逐项确认后才加入日历。关闭窗口保留本次输入、排版选项和结果草稿；这是当前进程草稿，不承诺应用强制结束后的恢复。API 配置离开详情、切换设置分类或主导航时先保护未保存改动。

“AI 整理”默认关闭，配置并授权有效模型后才能启用；开启时文字会发给所配服务，保存前检查结果。无配置时开关不可用，本机提取与规则排版仍可使用。完整 Marker 端侧模型移植尚未完成，详情见 [端侧推理说明](MARKER_HARMONY_REVIEW_2026-10-09.md)。

## 开始记录

1. 首页四个图标依次为“文字笔记、手写笔记、导入、提取”。点笔记或笔尖图标，选择“文字笔记”或“手写白板”，填写标题和所属项目，可另填主题标签，最后点“创建”。空标题使用类型对应的未命名标题，点击输入框不会清空已有输入；创建失败保留表单。
2. 文档默认只读，点“编辑”或“批注”后再写入。项目内点 ＋ 可新建或导入；模板中的“日记”等只提供结构。
3. 修改后查看保存状态。没有改动或已经保存，返回直接退出；有未保存内容时点“保存退出”，失败保留当前页面供重试。

主页和编辑器图标下方有短标签。向下阅读会收缩顶栏，点击空白处或屏幕上下边缘可展开；正在输入或批注时不会收缩。项目菜单和二级面板居中，使用图标及简短名称。

发布版首次安装为空。调试版自动加入一份真实的两页 PDF，在“示例资料”中打开即可检查阅读与批注，只加入一次，删除后不会在重启时重建。升级保留原资料；旧版本的示例也可能被编辑过，需要移除时自行放入回收站。

首页资料每次显示 12 项，点“显示更多资料”继续浏览。卡片右上角封面按钮已移除；长按文字笔记卡片，在菜单中选择“更换封面”。

## 使用手写笔

先在系统设置中完成星闪手写笔配对。白板、手机和 Pad PDF 批注默认允许手指与鼠标书写，可在笔设置关闭手指书写、仅使用手写笔。双指缩放；批注时点“拖动页面”再浏览和翻页。阅读顶栏为一行，伴读、稿纸和收藏收在“更多”；批注时增加紧凑笔工具。正文和稿纸共用顶栏，点击“正文/稿纸”或在画布落笔选择操作目标。设置图标展开颜色、大小滑杆、手指书写和橡皮模式；返回保存后恢复阅读顶栏。独立白板保留自己的紧凑工具条，窄分屏可横滑工具区域。

批注中点击返回或退出批注，会保存后回到只读并保留当前文件；再次返回才关闭资料。保存失败会保留内容并显示重试入口。关闭有待保存内容的稿纸分屏也会先等待保存。损坏笔迹数据会保留原记录并阻止覆盖，请检查原数据或备份。

支持对应笔身操作的设备：

- 双击：切换橡皮擦，再次双击回到先前的笔工具。
- 轻捏：呼出工具。分屏时先在要控制的画布落笔。
- 撤销/重做：恢复画笔、擦除或清空，最多保留 50 步。

PDF 在“更多”切换连续/单页阅读。单页按可用宽高完整显示，未放大时上下滑动翻页；放大后拖动浏览。左下角小块直接显示当前页/总页数，点击后在旁边输入目标页码并跳转。双指可放大，批注时先选“拖动页面”再浏览。墨迹和 PDF 页面一起缩放。笔身操作未被系统报告时，使用屏幕工具栏完成相同操作。笔尖压感、落笔延迟和防误触效果与系统、屏幕和笔型号有关。

## 使用本地助手

进入“墨客”，输入框旁的 ＋ 在附近展开资料菜单：引用资料库、导入文件、识别图片文字及移除引用。旁边独立选择助手与模型，模型配置从该菜单进入；新建对话按钮位于右上角更多左侧，撤回和删除放在更多菜单。阅读器右上角更多可打开“随堂稿纸”“AI 伴读”或恢复“仅显示正文”。删除、移除全部引用、清空伴读或撤回需确认，取消保留原记录。

| 操作 | 返回内容 |
| --- | --- |
| 提取要点 | 选定资料的原文片段和出处，便于核对 |
| 整理待办 | 原文中的任务候选；不自动创建任务、不猜测截止日期 |
| 输入关键词或问题 | 查找资料中匹配的原文，点击出处回到笔记或 PDF 页 |
| 资料概览 | 当前资料分类、数量与待办概况 |

不引用资料时可搜索资料库。空库先新建或导入；未找到结果可缩短问题、改用课程原词。手写笔迹尚未识别为文字，不能直接检索。PDF 要先通过阅读器的页面文字提取与校对，将确认后的文字保存后再查询。没有原文依据时不会生成答案。

处理过程中可点停止。切换会话或离开伴读页会取消请求，不把晚到内容写入下一篇文档。回答按标题、列表、表格、引用、代码与公式块排版；公式保留源文，不是完整 LaTeX 排版。

需要生成式问答时进入“设置 → AI 与模型 → 自配 API”，填写服务地址、实际模型 ID 和 Key，确认该地址的发送授权，测试后保存。只在选择 API 模式并主动请求时发送所选资料；可随时切回本地模式，费用与可用性由服务方决定。L1/L2/L3、工具权限、推理参数和题卡建议按配置提供，写入内容仍需确认。云 AI 尚未开放。

在支持 Function Calling 的 OpenAI 兼容/自定义流式模型中，可按工具权限查询整个资料库，再确认新建笔记/待办、分类、标签、双链、重命名、修改文字正文、收藏/置顶或待办完成状态。长正文会分段读取；更新须匹配版本，正在编辑的笔记需先结束编辑。PDF/手写原件不允许被工具覆写，设置、密钥及回收站未开放任意 AI 修改。Gemini/Anthropic 当前不提供这条原生工具链，外部 MCP 插件尚未接通。

## PDF 与日历

从首页、项目、墨客或智能提取导入的 PDF 会复制到应用本机目录，保留外部原文件。墨客与智能提取导入成功后能在资料库“外部参考”中找到。应用重启后按保存的副本文件名恢复当前本机路径；旧版仍可读取的外部 PDF 引用会迁移为应用内副本，不修改已有批注。成功入库后，移动或删除外部原文件不影响应用中的阅读；原 PDF 分享不包含应用内笔迹。

开发时使用同一模拟器和签名覆盖安装（`deploy_hap.bat` 使用 `install -r`）保留资料。重置模拟器、清除应用数据或卸载后重装会移除应用内资料，请先导出学习备份。已经缺失原件的旧资料需“重新关联原 PDF”，选择一次文件后就会保存本机副本。

调试版需要更多测试副本时，使用“设置 → 使用指引 → 导入阅读测试 PDF”或“导入快照测试 PDF”，再在“示例资料”打开。前者含可提取文字，后者由两页图片组成、无文字层，文字识别需要设备 OCR。发布构建不打包这两份 PDF 和预渲染图片，也不显示测试导入入口。已有本机资料不会因换用发布版被删除。

设备缺少 PDF Kit 时，调试版仅对与内置原件逐字节一致的 PDF 使用预渲染页面，可测试阅读、翻页和批注；不会替代其他 PDF 的内容。真实 PDF 解析及文字提取需要支持 PDF Kit 的设备。

旧示例可能只有元数据，没有实际 PDF 原件。错误页或更多菜单的“重新关联原 PDF”可为原记录选择文件，现有批注保留；有批注时不接受不同页数。请选该资料原来的文件，相同页数不代表内容一致，关联后核对笔迹对应位置；旧页面文字索引会清除，可重新提取。读取错误时不会在占位页落笔。

待办日历显示农历和传统节日，2026 年显示已核对的法定休息“休”和补班“班”。其他年份不推测调休。2026 年依据：[官方安排](https://www.beijing.gov.cn/cs/gncs/zcwj/202603/t20260327_4568275.html)。

## 备份与换机

文字阅读器的向上箭头可打开鸿蒙系统分享面板，分享当前文字；PDF 的更多菜单可分享原 PDF。由你选择目标应用或设备；原 PDF 不包含应用内笔迹，分享面板打开不等于送达。文字过长时使用文件导出。完整笔迹和题卡通过资料备份传递。

“设置 → 备份与传递”导出学习资料，再用文件恢复为副本。备份包括笔记、原 PDF、封面、笔迹、已校对文字和题卡；不含待办、日期备忘、回收站、对话、模型配置/密钥。每个附件上限 16 MB，总文件上限 32 MB，较大资料按课程分批。备份是明文文件，存放到自己可控的位置。云备份未开放。

附近传递需满足系统可信组网条件；无法连接时可以传递备份文件。卸载前先导出，并在另一设备确认文件可恢复。没有自动云同步。

## 常见情况

| 现象 | 处理 |
| --- | --- |
| 新建显示保存失败 | 保留标题，检查系统存储空间后重试；不要重复点击或退出尚未保存的内容 |
| 手写不落墨 | 先点右下角笔或顶栏“批注”并选择画笔；若曾关闭手指书写，可在笔设置开启。确认原页可读取，白板默认可用手指；使用笔时检查系统配对 |
| PDF 显示缺少原件 | 选择“重新关联原 PDF”并选择原文件，取消保留原记录；其他资料请单独导入 |
| 双击/轻捏没有动作 | 确认当前笔与系统支持该事件，在目标画布落笔后重试；同时可用工具栏 |
| 搜不到 PDF 原文 | 先提取并校对相应页文字；扫描页使用设备支持的 OCR，核对结果后保存 |
| 本地助手不能解释新问题 | 它提供原文检索与摘录，不是生成式模型；补充资料后查询原文 |

自配 API 没有响应时，检查地址、模型 ID、授权与服务余额，可停止或切回本地。首响应最多等待 45 秒、空闲间隔 30 秒、流式总时长 180 秒；非流式上限 60 秒。程序不会自动改写模型 ID。


## 资料引用、模型任务与伴读

墨客右上角“新建对话”位于更多左边。加号在输入框旁弹出原生菜单，分为添加资料、离线任务、模型任务；更多可复制对话、重新回答、撤回上一轮、删除当前对话或进入模型设置。生成讲解、自测题和比较观点需选择已配置并授权的自配模型，否则显示为灰色。菜单关闭后仍可继续输入。

左上角记录图标打开整个侧栏的对话记录页，可搜索标题和最近消息，按置顶、今天、最近七天及更早查看。每项更多可置顶或删除；选择记录后回到对话。点空白处、关闭按钮或再次点击记录入口恢复之前的侧栏。对话读取失败可重试或新建，失败时不会发送并覆盖原记录。

“引用库内资料”打开会话内选择区，按标题、项目、标签或正文关键词查找并选择引用。可以逐项添加，再关闭选择区继续提问；返回先关闭选择区。未引用资料时，本地提问仍可按关键词检索资料库原文。扫描 PDF 只检索已提取并校对的文字，不能仅凭文件名读取图像内容。

PDF 伴读默认本页范围，可切换为全部已校对页。范围会显示在对话中；翻页时结束正在生成的本页回答，保留已有文字。批注自动保存不会清空或打断同一文档对话。没有文字时可点“提取本页文字”，回到只读并完成保存后操作。多轮追问带入此前有效消息。伴读记录仍仅在当前进程记忆，退出应用不承诺恢复。

## 滑动调节笔控

在白板、稿纸或 PDF 的笔设置中拖动大小滑杆：普通笔 1–16、荧光笔 6–32、橡皮 8–64。各工具独立记住大小和墨水颜色；调节不会切回普通笔，切换前结束当前笔触。工具按钮背景、图标和小字共同突出；笔身快捷双击橡皮可恢复上一个墨水工具。选择橡皮后在更多笔设置选“区域消除”或“笔画消除”：前者擦除经过区域，后者删除命中笔画；均可撤销，取消接触恢复擦除前内容。PDF 橡皮按页面比例调整。

白板双指同时平移和缩放，全部抬起后可继续单指书写。写到边缘时抬笔后会显示更多区域，已有笔迹坐标不改变；稿纸可在更多笔设置点击“向下”。清空只作用于当前操作目标，确认后可撤销。
