# 墨语使用指引

适用版本：1.1.1，手机与平板。本版新增本地复习增强；手机和平板实际交互仍待验证。

## 收集与整理

首页“随手记”可以直接写正文，无需填写标题；支持 Markdown 和 `#标签`。输入停下后会保存独立本机草稿，点击“保存记录”才成为正式笔记。保存失败保留输入；看到“草稿未能保存”可重试。草稿停顿保存有 500ms 间隔，强制结束进程前的最后输入仍需核对。

首页采用 Notion 风格的文档工作台，上方提供新建笔记、手写笔记、导入资料和文字整理；随手记位于记录之前；下方按创建时间倒序显示文字记录，编辑旧记录不会改变它的历史位置。单击标题或正文摘要打开完整内容，右上角菜单可打开记录、置顶、收藏或移入回收站；正文编辑在完整阅读器中进行。点击“置顶”只看置顶记录。

首页“筛选”在手机和平板上均可展开日期日历与标签。日期上的点和数量来自真实文字记录，点击日期或标签筛选记录，再次点击日期或“清除筛选”可还原。侧栏始终显示私人项目树，项目展开状态沿用当前会话。

“资料库”独立提供书架、列表与时间流切换，显示设置和排序重启保留；“筛选”集中提供排序、阅读状态和多标签过滤。资料库关键词包含正文和校对过的 PDF 页文字，`#标签` 搜索全部标签。“清除筛选”返回全部资料。书架、列表和时间流中，每份资料右下角的“…”可重命名、移动分类或移入回收站；移动时可选择已有项目、空项目、“未分类”或填写新项目。标题与分类保存成功后才关闭表单，失败保留输入；删除仍需确认。

首页提供“新建笔记”“手写笔记”“导入资料”“文字整理”四个快捷入口。导入支持 PDF、Markdown、TXT、PNG、JPG／JPEG、WebP、BMP 和 GIF。图片原件按原格式保留，GIF 预览首帧。“文字整理”与阅读器提取入口可粘贴文字、选择图片或导入文件；设备不支持识别时，可粘贴或导入已有文字。

“导入资料”一次最多选择 20 份，默认同时显示支持的 PDF、文字和图片文件；按顺序复制到应用内并保存，部分失败不会撤回已成功导入的资料。从某个项目的资料库中导入，会归到该项目；首页导入默认进入资料库，未分类时不创建侧栏文件夹。PDF 以应用内副本阅读和批注，原文件保留。模拟器的电脑文件需要先复制进模拟器，再通过文件选择器导入，电脑上的盘符不会直接出现在应用里。

“保留原文”保持顺序与段落；“学习笔记”按明确标题和项目符号排版。需要时启用“合并图片断行”，并检查多栏阅读顺序、表格、公式、数字和日期。排版不会补充知识或猜测事实。原文与整理正文分开保留。

保存前检查标题、项目与正文，逐项选择需要创建的待办。待办建议显示原文行号，支持未完成勾选项；已完成或带否定条件的行动不自动加入。已选事项的日期有歧义时，先填写完整年月日，或取消勾选后只保存笔记；清空日期表示加入今天。草稿里的“今天／明天／后天”以提取当天为准，跨日恢复不会顺延。长文请分段处理。

搜索按完整标题、标题片段、标签、正文的顺序展示命中结果；PDF 校对文字命中可定位页码。修改关键词会取消旧检索，单份正文无法读取时保留其他结果并提供重新搜索。正则输入错误会显示修正提示；打开结果后才记录该次搜索。

## 项目与图谱

进入资料库后，点击侧栏项目打开对应资料，更多按钮打开项目操作。点击“新建项目”填写名称，可选八种细线图标与主题色；侧栏、项目菜单和快传列表沿用同一图标，旧项目自动兼容显示。保存失败保留输入。图谱的“新建主题”与项目共用持久化资料，空主题也可选择；点击两个节点可建立双链。

删除项目会将项目及其中资料一起移入回收站，侧栏在保存成功后移除。回收站可整项目恢复，也可逐篇恢复；遇到另一个同名项目时先重命名再恢复。空项目同样可恢复。

## 阅读与手写

主页“继续阅读”显示最近打开的资料；PDF 记录保存页码，再次打开时恢复该位置。翻页记录合并 600ms 内的变化；正常退出等待保存。“未打开／阅读中／已到末页”是浏览状态，到达末页不表示已完成学习；文字笔记没有伪造的阅读百分比。

自由白板、PDF、图片和手写笔记共用同一套工作台、顶部工具栏与笔迹画布，默认只读。点击笔、荧光笔或橡皮即可进入批注并选中；锁图标也可切换“只读／可批注”，再次锁定会先保存。原页和已有笔迹必须正常读入才能进入批注。图片与 PDF 原件始终保持不变，新增笔迹独立保存。PDF 支持翻页、页面文字提取和原件重新关联；图片按原始比例显示。

工具栏始终可见，滚动或轻触正文不会隐藏；已移除旧的呼出导航、控制台手柄和边缘感应区域。左下控制条直接提供上一页、下一页、页码跳转和连续／逐页切换；到达首尾时禁用相应翻页按钮，加载未就绪时不接受翻页。顶栏“页面总览”可打开页码网格；正文支持双指缩放，范围 100%–250%，不再叠加中间的缩放浮窗。原件不可读或阅读组件未就绪时，页面上方显示原因，不允许在空白替代页上批注。新增离线兼容路径尚待设备验证，实际支持情况以设备提供的系统能力为准。

“自由白板”创建并再次打开它自己的画布，不借用已有手写笔记；顶栏没有文件名和文档标签。普通手写笔记、PDF 和图片保留文档标签。

点击“图形工具”，选择直线、矩形、椭圆或箭头后拖动绘制。图形沿用普通笔的颜色和宽度，使用同样的撤销、重做和橡皮擦；调色与粗细仍在双击笔的浮层中。手写和稿纸的“纸张与视图”可选择白纸、横线、方格，分别随对应资料保存；底纹不是笔迹，橡皮不会擦掉它。“回到起点”恢复初始缩放和平移，不清除笔迹，只读时也可使用。PDF 和图片的原始背景不替换为纸纹。

手掌图标切换页面拖动；双指缩放和平移。手指书写可在笔设置里开关，开启时单指落笔、双指浏览。硬件笔的双击／轻捏快捷操作依赖设备支持。顶部文档标签可切换最近打开的资料；切换、关闭当前标签或新建手写笔记前等待正文和随堂稿纸保存，失败时保留当前资料。

手机工具栏保留至少 44vp 的锁定、笔、荧光笔和橡皮点击区域，次要状态文字收起，操作名称仍可由读屏获取。笔接管输入时取消尚未提交的手指笔迹，避免把误触提交为墨迹；物理笔与手掌过滤效果由设备验证。

笔、荧光笔、橡皮和撤销／重做单击立即生效。双击笔或荧光笔图标，展开粗细预设、滑杆、调色盘和自定义颜色；选中橡皮后，点击旁边的擦除方式可选择“区域擦除”或“笔画擦除”：前者只擦经过的区域，后者删除碰到的整笔；橡皮按钮的「区／笔」角标显示当前模式。双击橡皮仍可打开设置及直径。也可从更多菜单打开“画笔设置”。清空需要确认，之后可撤销。返回先收起已打开的设置卡片；正常返回会等待正文、批注和随堂稿纸保存后离开，不要求清空。保存失败保留原页面，可继续阅读或重试保存。锁定按钮只结束批注并保存，仍停留在阅读器。

导出文字或截图先显示操作说明，再由你选择保存位置。文字可选择 Markdown 或 TXT，均保留正文原文；PNG 截图只包含当前可见正文与笔迹，不包含工具栏、随堂稿纸及屏幕外的内容。需要保存整份资料和笔迹时使用文件备份。分享原 PDF 或原图不包含新增笔迹；导出原图保留完整原始文件，导出带笔迹的当前页面请选截图。成功显示结果，失败留在弹窗中重试；系统选择器中取消不写入新文件。

随堂稿纸左上角“…”可打开画笔设置、选择空白／横线／方格、重置稿纸视图或清空笔迹。清空需要确认，只作用于这张稿纸。已有笔迹在后台读取，显示加载状态且暂不接受书写；未修改时可直接关闭，原笔迹保留。

阅读器顶栏显示已打开的资料标签。按住文件名拖到阅读区右半边，出现“放到这里分屏阅读”后松开，可将该资料放到第二栏；也可点击顶栏“分屏阅读”搜索选择。支持现有阅读器能打开的 PDF、Markdown／TXT、图片和手写资料任意组合，包括两份相同格式。宽屏左右排列，手机上下排列，两边各自保存；切换、关闭标签或收起分屏前保存当前两份资料，失败时保留分屏并可重试。顶栏搜索可继续打开资料，最多保留八个标签，当前分屏的两份资料不会被挤掉。文字笔记的原有目录、双链和侧栏入口保留。

文字笔记编辑支持选区格式、代码块、表格、网页链接、双向链接和任务勾选；可撤销和重做。宽屏可打开实时分栏预览，手机在源码和预览之间切换。正文编辑区内部滚动，底部显示保存状态，保存失败可点击重试。外接键盘支持 Ctrl+B／I／Z／Shift+Z／Y／S。

手机待办默认展示所选日期所在的一周，“展开月历”可选择其他日期。完成进度按当日真实任务计算；勾选保存成功后切换，删除需要确认。添加待办失败时保留标题和引用，重试成功后才关闭输入框。

## 自测、备份与隐私

在“设置 → 外观与动效”选择白蓝、白青、白绿、白玫、暖砂、墨紫、黑白或雾蓝；主题保留不同强调色，共用纸面背景与中性侧栏；卡片预览实际配色。配色与“跟随系统／浅色／深色”分别选择，保存后立即生效并在重启后保留。阅读器与弹窗同步切换，原图、封面和已选笔色保留。

课程复习中手动填写问题、参考答案和引用原文。先回忆再揭示答案，用“不会／模糊／掌握”安排下次复习。

1.1.1 新增本地学习增强：复习页的“学习概况”按当前课程汇总已打开资料、未自测、待巩固和最近自评掌握的题卡，并逐份显示阅读位置与到期数量。“只看待巩固”依据最近一次“不会／模糊”反馈筛选；到期题中优先复习这些题，未到期题不会被提前安排。历史遗忘次数保留，最近一次已自评掌握的题不再归为待巩固。

题卡列表支持查看原文或编辑问题、答案与引用，修改内容不会重置复习反馈、次数、原文页码和下次日期。保存失败保留输入，可重试；有未保存内容时，关闭、查看原文或改编辑另一道题会先保留当前输入，可保存或明确放弃后继续。学习概况只依据本机记录，读到末页或一次自评不代表已经学会。

设置中的“备份与快传”按现有文件夹分类。点击文件夹前的勾选框选择整夹，也可展开文件夹逐份选择；部分选择显示横线。选择整夹包含未展开或尚未显示的文件。资料包包含所选正文、原 PDF、原始图片、封面、笔迹、已校对文字和关联题卡。恢复创建副本并保留原分类；文件未加密，请妥善保管。卸载前先备份，升级安装应保持签名一致。快传通过系统分享面板选择接收设备；收到资料包后在本页导入副本。系统面板打开不代表送达，设备发现和传输方式由系统提供。

隐私政策可在“设置 → 隐私与数据”查看。首次声明由平台托管配置提供。


阅读器文件名统一显示在最上方的资料标签，正文区域不再重复一行标题。批注工具栏的“更多文档操作”可打开随堂稿纸、截图、导出文字及分享原件。PDF 读取超时会显示原因并提供“重试读取”；正常返回继续保留已保存的批注与稿纸。
