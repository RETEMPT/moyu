# 墨语使用指引

默认本地资料与离线助手，无需登录、API Key 或联网。左下角“设置”按资料库、指引、主题、AI、云服务和协议分区；手机使用同一设置页面。云服务、云 AI 和云备份标记未开放，本地备份可用。

## 开始记录

1. 首页四个图标依次为“文字笔记、手写笔记、导入、提取”。点笔记或笔尖图标，输入标题后点勾选图标创建；命名面板的笔记/笔尖图标可切换类型。
2. 文档默认只读，点“编辑”或“批注”后再写入。项目内点 ＋ 可新建或导入；模板中的“日记”等只提供结构。
3. 修改后查看保存状态。没有改动或已经保存，返回直接退出；有未保存内容时点“保存退出”，失败保留当前页面供重试。

主页和编辑器图标下方有短标签。向下阅读会收缩顶栏，点击空白处或收缩栏可展开；正在输入或批注时不会收缩。项目菜单和二级面板居中，使用图标及简短名称。

首次安装为空。升级会保留原资料；旧版本的示例也可能被编辑过，需要移除时自行放入回收站。

## 使用手写笔

先在系统设置中完成星闪手写笔配对。默认笔写、手指浏览，双指缩放；没有笔时点手掌图标开启手指书写。PDF 顶栏的书本/笔尖图标切换阅读与批注，画笔、荧光笔、橡皮擦及撤销/重做固定显示，滑杆图标展开颜色和笔粗。窄分屏可横滑工具区域。

支持对应笔身操作的设备：

- 双击：切换橡皮擦，再次双击回到先前的笔工具。
- 轻捏：呼出工具。分屏时先在要控制的画布落笔。
- 撤销/重做：恢复画笔、擦除或清空，最多保留 50 步。

PDF 双指可放大，放大后拖动浏览；开启手指书写时使用双指浏览。墨迹和 PDF 页面一起缩放。笔身操作未被系统报告时，使用屏幕工具栏完成相同操作。笔尖压感、落笔延迟和防误触效果与系统、屏幕和笔型号有关。

## 使用本地助手

进入“墨客”，输入框旁的 ＋ 居中菜单包含新建对话、引用、导入、识别、AI 配置、撤回与删除；阅读器也可打开伴读。删除、清空伴读或撤回需再确认，取消保留原记录。

| 操作 | 返回内容 |
| --- | --- |
| 提取要点 | 选定资料的原文片段和出处，便于核对 |
| 整理待办 | 原文中的任务候选；不自动创建任务、不猜测截止日期 |
| 输入关键词或问题 | 查找资料中匹配的原文，点击出处回到笔记或 PDF 页 |
| 资料概览 | 当前资料分类、数量与待办概况 |

不引用资料时可搜索资料库。空库先新建或导入；未找到结果可缩短问题、改用课程原词。手写笔迹尚未识别为文字，不能直接检索。PDF 要先通过阅读器的页面文字提取与校对，将确认后的文字保存后再查询。没有原文依据时不会生成答案。

处理过程中可点停止。切换会话或离开伴读页会取消请求，不把晚到内容写入下一篇文档。回答按标题、列表、表格、引用、代码与公式块排版；公式保留源文，不是完整 LaTeX 排版。

需要生成式问答时进入“设置 → AI 配置 → 自配 API”，填写服务地址、实际模型 ID 和 Key，确认该地址的发送授权，测试后保存。只在选择 API 模式并主动请求时发送所选资料；可随时切回本地模式，费用与可用性由服务方决定。L1/L2/L3、工具权限、推理参数和题卡建议按配置提供，写入内容仍需确认。云 AI 尚未开放。

## PDF 与日历

从首页、项目或墨客导入的 PDF 会保存本机副本，墨客导入成功后也能在资料库“外部参考”中找到。重启后仍可阅读，原 PDF 分享不包含应用内笔迹。

需要测试文件时，使用“设置 → 资料库 → 导入阅读测试 PDF”，再在“示例资料”打开《墨语阅读测试》。它是真实的两页 PDF，需手动导入。仓库中旧示例只有元数据、没有实际 PDF 原件，本版本补充新的测试文件；找不到自己原有的文件时应从本地备份恢复或重新选择原文件。

待办日历显示农历和传统节日，2026 年显示已核对的法定休息“休”和补班“班”。其他年份不推测调休。2026 年依据：[官方安排](https://www.beijing.gov.cn/cs/gncs/zcwj/202603/t20260327_4568275.html)。

## 备份与换机

文字阅读器的向上箭头可打开鸿蒙系统分享面板，分享当前文字；PDF 的更多菜单可分享原 PDF。由你选择目标应用或设备；原 PDF 不包含应用内笔迹，分享面板打开不等于送达。文字过长时使用文件导出。完整笔迹和题卡通过资料备份传递。

“设置 → 资料库 → 本地备份”导出学习资料，再用文件恢复为副本。备份包括笔记、原 PDF、封面、笔迹、已校对文字和题卡；不含待办、日期备忘、回收站、对话、模型配置/密钥。每个附件上限 16 MB，总文件上限 32 MB，较大资料按课程分批。备份是明文文件，存放到自己可控的位置。云备份未开放。

附近传递需满足系统可信组网条件；无法连接时可以传递备份文件。卸载前先导出，并在另一设备确认文件可恢复。没有自动云同步。

## 常见情况

| 现象 | 处理 |
| --- | --- |
| 新建显示保存失败 | 保留标题，检查系统存储空间后重试；不要重复点击或退出尚未保存的内容 |
| 手写不落墨 | 确认系统配对、进入 PDF 批注、选择画笔；手指默认不落墨，可以主动开启手指书写 |
| 双击/轻捏没有动作 | 确认当前笔与系统支持该事件，在目标画布落笔后重试；同时可用工具栏 |
| 搜不到 PDF 原文 | 先提取并校对相应页文字；扫描页使用设备支持的 OCR，核对结果后保存 |
| 本地助手不能解释新问题 | 它提供原文检索与摘录，不是生成式模型；补充资料后查询原文 |

自配 API 没有响应时，检查地址、模型 ID、授权与服务余额，可停止或切回本地。首响应最多等待 45 秒、空闲间隔 30 秒、流式总时长 180 秒；非流式上限 60 秒。程序不会自动改写模型 ID。
