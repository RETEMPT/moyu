| 官方资料 | 可借鉴的交互 | 本项目实现 |
| --- | --- | --- |

以上是基于官方交互说明形成的设计判断，未声称对这些软件执行了性能对比。帧率、耗电和真机手感仍需专项测量。

## 封面闭环

- 墨线：深色几何；雾蓝：山形层叠；青野：植物线条；纸砂：暖色书页。样式随包分发，选择不调用图片生成或网络。
- 首页主要操作、四张统计卡、顶栏菜单与搜索、侧栏导航使用同一套圆角线框 SVG，图标承载区域一致；手机端主要操作和侧栏导航采用至少 44vp 触控高度。应用启动图标沿用原有墨笔标志。
- 相册授权 URI 先复制到应用 `filesDir/covers`，再保存笔记元数据，限制 12 MB。成功后才关闭选择器，失败保留当前封面和错误反馈。
- 封面不写进 Markdown 正文。编辑器同步外部元数据，避免后续自动保存把封面、标签、收藏回退。
- 列表刷新键包含封面、分类、收藏与置顶；打开资料时按 ID 读取当前笔记，避免旧卡片闭包把旧封面带进阅读器。
- 替换或移除封面后清理无引用的应用内图片；彻底删除笔记时清理应用内副本，外部相册文件和越界路径不参与删除。

## 模型配置与工具能力

配置分为“连接／输出／工具”，手机全幅，宽屏限制宽度和高度，中间滚动、底部操作固定。档案切换保留本次面板中的草稿，关闭有未保存输入时可继续编辑或明确放弃；草稿不宣称跨重启恢复。

“保存并启用”与“测试连接”是独立结果。保存失败不广播启用，连接测试期间锁定表单，密钥隐藏不会改变原值；切换服务主机不沿用旧主机密钥。地址、模型 ID、温度、输出长度和工具轮数执行校验。

[DeepSeek 官方更新](https://api-docs.deepseek.com/updates/)记录旧的 `deepseek-chat`／`deepseek-reasoner` 已停用；因此取消这两项快捷预设，保留当前 Pro／Flash 和可编辑的服务示例。已保存的用户模型 ID 不被静默替换，所有 ID 与额度仍应在各自服务商控制台核对。

| 能力 | 兼容 API | Gemini | Anthropic |
| --- | --- | --- | --- |
| 文本与流式回答、系统提示词 | 支持 | 支持 | 支持 |
| 非流式回答 | 支持，完整返回后显示 | 支持 | 支持 |
| 当前原生工具调用 | 流式支持 | 暂未接入 | 暂未接入 |
| 手动确认方案 | 支持 | 支持 | 支持 |
| 语义检索 | 需 embeddings 接口和主动开启 | 需向量模型和主动开启 | 默认本地关键词检索 |

内置 6 个只读工具：检索笔记、列出笔记、阅读全文、读取章节大纲、知识库统计、待办列表。5 个写入工具：创建待办、添加标签、建立双链、修改分类、新建笔记。

工具设置实际限制执行器权限，可关闭、只读或写入前确认；配置 1–6 轮上限。未知字段、错误类型、空值、无效日期和非法双链目标在执行前拒绝。写操作等待文件及快照保存，目标必须唯一，模糊或同名标题要求笔记 ID。方案逐项记录已完成动作，部分失败可重试并跳过已记录项目。

取消请求、切换会话和离开页面使旧回调失效。非流式调用和已开始的文件写入不能撤回，但取消后不开始下一项工具。执行记录保存失败时保留提示；文件与会话快照仍属于不同存储步骤，异常断电的完整事务恢复不在本轮实现范围内。

快捷场景共六类：自测题卡、比较观点、智能规划、文档提炼、双链关联和知识全景。回答仍需资料依据；没有依据应说明缺少资料，不生成演示事实。

## 数据范围与验证边界

默认关键词检索无需网络。开启语义检索后，待索引笔记片段发送至所配向量服务；AI 回答向所配模型发送问题、选中的文档与检索片段。向量失败回退关键词检索，正文变更使缓存更新，取消后的结果不会写入缓存。应用配置未增加独立的密钥加密层，不再声称“沙箱私有加密”或“零云端留存”。

- 服务回归：87 项通过，覆盖 OCR／Markdown／PDF 的原有路径，以及封面文件、列表刷新、模型校验、保存失败、参数校验、唯一目标、工具权限、取消、循环上限、非流式、附加提示词和向量缓存。
- ArkTS、资源、HAP 构建通过；使用本地 API 26 模拟器覆盖安装，保留应用数据并验证前台启动。
- 模拟器交互：封面选择、更换、移除、重启保留和阅读页同步；首页统计；模型配置回填；新档案草稿关闭拦截。相册复制的失败与清理使用平台适配器替身测试。
- 390vp 约束视口下复核首页双列快捷操作、单列可读书架、封面选择和保存、侧栏抽屉、AI 工作区；响应式断点依据 AppShell 实际宽度更新。该约束仅用于模拟器验证，正式构建已恢复全屏视口。
- 手机、键盘、真实相册照片、实际模型联网、真实 OCR 和 PDF 手写性能必须分别验收。390vp 约束视口只能验证窄屏布局，不能替代真实手机触控和性能测试。
- 云端 CI 运行结果以 PR 当前提交的检查为准；完整产品清单见 [工作流验收记录](WORKFLOW_REVIEW.md)，未完成项保留明确状态。
