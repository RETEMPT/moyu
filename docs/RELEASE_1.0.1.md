# FlowMind（墨语）v1.0.1

发布日期：2026-10-07。GitHub 源码与未签名开发构建更新，手机与 Pad 共用一个版本。未提交应用市场，尚未完成双端全量真机验收。

## 本次更新

- AI 设置精简为“自配 API / 云端 AI”；连接配置直接显示，输出、检索、工具权限和档案管理按需展开。聊天支持多行提问、横向引用标签，快捷场景先填入再发送，减少重复入口。保留手机五项底栏及与 Pad 共用的图标。
- 云端 AI 仅提供 Seed、Qwen、DeepSeek、GLM 的本机模型预览目录，明确尚未开放，不接后台或计费。自配接入新建空密钥、未授权草稿，保留原配置及其未保存输入。目录模板不是各厂商真实帐号连通或全部能力的保证。
- 首次隐私说明支持选择离线使用。远程 AI 发送授权独立绑定地址与协议，默认关闭；聊天、测试和向量入口统一检查授权及 HTTPS，不跟随重定向。模型密钥由系统密钥库保护，以 AES-GCM 密文保存；旧配置迁移失败保留原数据，提供重新填写、移除密钥和确认重置。
- 三类协议复用实际流式传输，修复中文字节分片、HTTP 状态确认、错误、取消和重复终止处理；兼容协议保留工具及思考增量。消息撤回等待保存，失败保留原对话，已删除会话不会因此恢复。
- 正文、快照、对话和阅读器保存加强排队与失败保护；合法空库保持为空，损坏数据阻止覆盖。附近课程传递试用可信设备与加密临时库，核验分片、摘要、期限和目标结果，确认接收后导入副本。
- 发布范围统一为 phone/tablet，移除未使用的原生模板，开启保留 JSON/协议字段的发布混淆。补齐同源隐私页面、商店材料、双端证据模板和默认严格的市场提交检查。

## 下载与使用

发行页面：[v1.0.1](https://github.com/RETEMPT/moyu/releases/tag/v1.0.1)。标签自动提供源码 ZIP/TAR。

| 附件 | 用途 |
| --- | --- |
| `FlowMind-1.0.1-HarmonyOS-unsigned.zip` | release APP、从最终 APP 提取的同内容 HAP、构建信息及内部校验值；手机与 Pad 共用，设备安装仍需适用签名 |
| `SHA256SUMS.txt` | 外部附件及包内文件的 SHA-256 校验值；不等同于数字签名 |
| `BUILD_INFO.json` | 对应源码提交、版本、SDK、验证范围、文件大小和摘要 |

统一包名 `com.retempt.flowmind`，版本名称 `1.0.1`，内部版本编号 `1001001`。编号独立递增，兼顾已发布 v1.0.0 与此前内部候选构建的升级路径。兼容 SDK `6.1.1(24)`，目标 SDK `26.0.0`，HarmonyOS runtime；未验证独立 OpenHarmony 系统。

开发者检出 `v1.0.1` 后，在 DevEco Studio 为实际设备配置有效签名再构建：

```powershell
.\build_hap.bat -StudioDir "<DevEco Studio 安装目录>" -BuildMode release -AppPackage -Clean
```

`release` 构建模式不自动产生正式签名。升级需保持应用身份及签名一致；失败时先核对签名、系统版本和设备连接，先导出学习资料，避免通过卸载处理升级问题而丢失数据。

## 数据与能力边界

- 核心学习功能本地可用，团队不运营云端 AI、云盘、订阅或用户帐号。自配 API 按所选服务发送资料，费用和留存规则由服务商决定。云端目录不会发送资料。
- 本版本关闭整包系统备份；换机和卸载前使用“外观与数据 → 备份与附近传递”导出学习资料，换设备需重新配置密钥。资料导出为明文，不包含模型配置/Key、对话、待办/日期备忘和回收站。
- 附近传递是手动导入副本的试用能力，依赖同签名、系统可信组网及设备权限；双端实测尚待完成，不提供异地自动同步、冲突合并或云盘。
- 尚无支付、Word 正文解析、原 PDF 嵌入批注导出、长图或打印。尚未完成真实 HUKS、各模型帐号联网、键盘/大字体/动画性能、双设备互通和升级验收，不承诺帧率、零丢失或学习成效。

## 验证

170 项服务回归与 11 项发布门槛测试、GitHub CI、干净 release HAP/APP 构建通过。实际 APP 的身份、版本、设备、权限、备份设置及发布模式检查通过，SDK 正确拒绝未签名 HAP。服务测试使用平台替身，不能替代真机；构建仍存在既有弃用告警。

应用市场还需真实发布资料与托管隐私网址、AGC/资质核对、正式发布签名及对应本次包的真机报告和截图。严格市场检查将这些缺项列为阻断，不影响本次明确标注范围的 GitHub 开发构建发行。详见 [上架准备](APP_MARKET_RELEASE.md)、[AI 界面说明](AI_INTERFACE.md) 与 [发布材料及验收](../release/README.md)。
