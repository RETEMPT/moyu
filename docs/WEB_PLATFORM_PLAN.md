# 私人云盘与公开资料库发展方向

资料平台将作为墨语本地工作台的延伸，帮助用户发现内容、管理个人资料，并在不同设备上继续学习。私人空间、公开内容与云AI服务各有清晰职责，通过资料身份和来源相互连接。

## 平台的产品价值

| 方向 | 主要能力 | 用户价值 |
| --- | --- | --- |
| 私人资料空间 | 文件夹、上传下载、分类、回收站与容量管理 | 集中管理自己的学习资料 |
| 跨设备取用 | 资料副本、版本关联、恢复和可选应用连接 | 在手机、平板和网页之间继续使用 |
| 公开资料库 | 分类、标签、关键词、详情、预览与授权下载 | 发现来源清楚、适合当前学习目标的内容 |
| 云AI工作区 | 所选资料处理、任务状态、引用和结果采纳 | 围绕同一份资料完成理解和整理 |
| 作者与专题 | 作者介绍、主题合集、资料更新和反馈 | 建立有上下文的内容组织方式 |

## 使用方式

公开资料库面向内容发现：用户从分类或搜索进入详情，了解作者、来源、许可和版本，再按许可范围预览或下载。资料可以主动导入墨语，在本地继续研读和批注。

私人空间面向个人积累：资料按项目与文件夹组织，可查看容量、保留版本并导出。网站账号只服务用户主动选择的云端能力，基础应用无需依赖网站登录。

内容建设从自有和获得授权的资料开始，后续逐步提供作者投稿、专题维护与资料更新机制。公开资料的来源和许可随内容展示，用户可以反馈错误或授权问题。

## 服务模式

公开资料库提供基础发现与访问，私人云盘根据容量、流量、版本保留和支持范围设计可选套餐。云AI权益单独说明，也可以按需要组成服务组合。

服务界面清楚展示空间、用量、期限和导出方式。空间不足或服务到期时，保留明确的读取、整理和迁移路径，让用户能持续管理已有内容。

## 数据与技术布局

网站将分为公共目录、私人文件区、AI工作区和管理服务。身份与逐对象权限检查保护私人资料；订单与用量记录负责权益管理；对象存储承载文件，数据库维护资料关系与状态。

私人存储将根据使用需要区分两种能力：

- 加密副本：设备端加密后保存，适合由用户控制密钥的备份与跨设备传递。
- 网页资料管理：支持在线预览和相应处理，由服务端按账号权限隔离文件。

公开资料是经过授权可以展示的内容，与私人目录分开管理。搜索、分享和AI处理均使用明确的资料范围，不因公开标签或分享操作暴露私人内容。

技术方案见[云服务与云AI设计](CLOUD_AI_DESIGN.md)，现有客户端结构见[架构](ARCHITECTURE.md)。

## 未来扩展

1. 建立资料目录、详情与授权信息，打通发现、下载和本地导入。
2. 完善私人空间、文件管理、版本恢复和可选应用连接。
3. 引入与资料关联的云AI任务，让结果能够回到原文并被保存为学习成果。
4. 逐步发展作者专题、机构资料域和开放接口，扩大优质内容的组织与复用方式。

平台演进将同时关注存储与下载成本、访问体验、内容维护和数据恢复能力。更完整的安排见[未来开发方向](ROADMAP.md)。
