# 应用市场发布准备

更新：2026-10-04。目标是成功上架鸿蒙应用市场；当前仍处于开发与评审阶段，未提交审核，未宣称已上架。

## 首发范围

本地课程资料、Markdown 笔记与封面、图片 OCR 校对、PDF 阅读/笔迹/页面文字、关键词检索、题卡自测与复习、本地资料备份。远程 AI 使用用户自行配置的服务，核心离线功能不要求 Key、应用帐号或团队云服务。

手机继续保留首页、资料、AI 墨客、待办、图谱五项底栏，与 Pad 复用 SVG 图标。新增学习功能在现有首页、阅读器和设置中提供入口。

## 可复现构建

先安装并同步工程对应的 DevEco Studio/SDK。可通过 `DEVECO_STUDIO_HOME` 或 `-StudioDir` 指定安装路径；脚本校验环境，不生成或修改签名材料。

```powershell
# 开发 HAP
.\build_hap.bat -StudioDir "<DevEco Studio 安装目录>"

# 发布模式 APP 打包验证
.\build_hap.bat -StudioDir "<DevEco Studio 安装目录>" -BuildMode release -AppPackage
```

APP 的输出在 `build/outputs/default/`，HAP 在 `entry/build/default/outputs/default/`。签名为空时构建器会跳过签名；release 参数或成功生成 unsigned APP 均不表示可以提交市场。签名文件与密钥保留在安全环境，不能提交 Git。

## 新功能真机检查

- [ ] 在无网络、无 Key 的条件下完成建笔记、OCR/文字校对、PDF 阅读、搜索、手动题卡、复习和备份；确认本地能力支持当前设备。
- [ ] PDF 文字层/扫描页 OCR 各一份；校对后搜索命中真实页码，回答引用与题卡查看来源能正确跳页。
- [ ] 保存页面文字时快速手写，保存并退出后重开；提取过程取消，不覆盖旧笔迹与已提取页面。
- [ ] AI 生成时关闭/返回/断网/错误 Key；停止后不更新已离开的页面，不保存未经确认的题卡。
- [ ] 手机小屏、系统大字体与软键盘；标题/资料查找/答案/校对区可滚动，按钮不被键盘遮挡，底栏在键盘收起后恢复。
- [ ] 超过一组资料/题卡时，过滤与分页可找到所有项；课程移动后计数正确，删除原资料不再进入待复习队列，回收站恢复后再可使用。
- [ ] 将包含 PDF、封面、笔迹、双链与卡片的备份移至另一设备，检查真实附件可读及数量一致；重复导入、题卡保存失败与再次导入。
- [ ] 文件选择取消、空间不足、损坏/超大备份和附件失败；未覆盖原资料，失败提示可理解，局部导入状态准确。

完整现有功能清单见 [WORKFLOW_REVIEW.md](WORKFLOW_REVIEW.md)。记录版本、日期、设备和失败截图；未执行项保持未勾选。

## 提交材料口径

介绍以“整理课程资料、查证原文、自测复习”为主。不得宣称云同步、官方 AI 服务、准确率/效率提升、零丢失、硬件防误触、独立 OpenHarmony 兼容或全功能覆盖，除非具备对应测试或审核证据。

建议先内部测试，再邀请学生使用，依据 [价值评估方案](CONTEST_VALUE_REVIEW.md) 留下匿名反馈和修复记录。只有发布签名、设备质量、材料与声明符合要求后才正式提交。

官方参考：[应用分发与测试](https://developer.huawei.com/consumer/cn/appgallery/devstart/)、[应用提交](https://developer.huawei.com/consumer/cn/app/submit/)、[Hvigor 命令行构建](https://developer.huawei.com/consumer/en/doc/harmonyos-guides-V14/ide-command-line-building-app-V14)。流程和要求以提交时官方指南与 AGC 实际校验为准。
