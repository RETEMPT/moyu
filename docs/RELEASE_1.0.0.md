# FlowMind（墨语）v1.0.0

发布日期：2026-10-05。这是 GitHub 源码与未签名开发构建的首次发行，不是应用市场版本。手机/Pad 全量真机验收尚未完成，正式设备安装需要有效的设备适用签名，市场提交需要发布签名及相应审核材料。

## 主要改进

- 图片 OCR 使用端侧实际结果，校对后进行本地或可选 AI Markdown 排版，编辑标题/分类/正文、确认待办后保存；失败保留输入并支持重试。
- 真实 PDF 导入、原页阅读与笔迹；选择 1～30 页提取文字，扫描 OCR 可选，校对后进入搜索和 AI 检索，引用可跳回来源页。保存笔迹保留已提取文字。
- 首页课程统计、离线手动题卡、可选 AI 题卡预览、回忆后看答案、复习反馈与到期队列。引用需匹配原文，答案仍需人工核对；学习自评不等同于成绩。
- 学习资料备份保存笔记、PDF、封面、笔迹、已校对文字和题卡，恢复创建副本，支持失败重试和唯一内部双链重连。随包示例恢复后仍标为示例。
- 手机保留首页、资料、AI 墨客、待办、图谱五项底栏，与 Pad 共用 SVG 图标；Markdown 封面支持离线样式、相册、更换与移除。
- 多模型档案、六类研读快捷场景、11 种笔记/待办工具、写前确认、停止与过期回调处理；主题、减少动态效果、数据与隐私入口。

## 下载与使用

发行页面：[v1.0.0](https://github.com/RETEMPT/moyu/releases/tag/v1.0.0)。GitHub 自动提供对应标签的源码 ZIP/TAR。

| 附件 | 用途 |
| --- | --- |
| `FlowMind-1.0.0-HarmonyOS-unsigned.app` | release 模式 AppPack，供开发者检查与后续签名发布准备；不能直接当作市场发布包 |
| `FlowMind-1.0.0-HarmonyOS-unsigned.hap` | release 模式 entry HAP，供支持相应条件的开发设备/模拟器测试，正式设备需有效签名 |
| `SHA256SUMS.txt` | 附件完整性校验值，核对下载是否完整；校验值不是数字签名 |
| `BUILD_INFO.json` | 构建对应的提交、版本、SDK 与文件大小信息 |

当前工程：`com.retempt.flowmind`，`versionName: 1.0.0`、`versionCode: 1000000`，HarmonyOS runtime，兼容 SDK `6.1.1(24)`、目标 SDK `26.0.0`。应用使用 HarmonyOS PDFKit/OCR 等系统 Kit，本次未验证独立 OpenHarmony 系统。

开发者可检出 `v1.0.0`，在 DevEco Studio 同步 SDK，按实际设备/发布目标配置签名后构建。可选命令行：

```powershell
.\build_hap.bat -StudioDir "<DevEco Studio 安装目录>" -BuildMode release -AppPackage
```

`-BuildMode release` 不会自动补充签名材料。安装或更新失败时先核对设备连接、系统兼容性和签名一致性，不要先卸载应用；卸载可能删除本地资料。

## 数据与能力边界

- 核心笔记、阅读、关键词搜索、手动题卡和复习本地可用。团队不运营云盘或 AI 服务，不要求注册墨语帐号；远程 AI 使用用户配置的服务，启用后会发送相关资料并产生服务商费用。
- 学习资料备份是明文文件；单附件上限 16 MB、备份文件上限 32 MB，可按课程分批。它不包含待办/日期备忘、回收站、对话、模型档案或 Key。系统备份是另一项机制，目前其配置允许备份，实际范围和 Key 排除尚待验证。
- 尚未实现自动云同步、支付、Word 正文解析、原 PDF 嵌入批注导出、长图与打印；PDF 检索只覆盖已提取并保存的页面文字。
- 本轮未进行全量真机验收、真实模型联网评测或学生试用；不宣称全功能覆盖、动画帧率保证、成绩提升或收入验证。
