## 本次完成的改进

- 图片 OCR 使用实际端侧识别结果；无文字、解码失败和设备不支持均报告错误，不再返回固定的考试通知。解码限制长边，成功与失败路径均释放文件、图像和位图。
- 文字处理形成“导入／粘贴 → 校对 → 本地或 AI 排版 → 编辑和核对 → 保存”的完整流程。默认本地处理；用户开启 AI 后才把校对文字发送给已配置的模型。
- 提供保留原文、学习笔记两种 AI 排版方式；模型响应按字段校验，错误或缺少正文时使用原输入降级。日期、公式、代码等原文另行保留，不把模型 JSON 当成识别原文。
- 标题、Markdown 正文、保存分类、待办日期均可编辑；默认不选择日历任务和建议关联。模糊日期提示确认，未确认时保留截止说明并暂存今天，不猜测年份。
- 保存先写正文和笔记快照，再写待办；失败保留编辑界面，重试使用相同 ID，避免重复笔记与待办。关闭弹层保留本次应用运行中的输入及排版草稿；不宣称跨重启恢复。
- 窄屏首次打开不被侧栏／上下文遮住，抽屉互斥，选择资料、分类或对话后收起；系统返回优先关闭弹层、抽屉，再处理阅读器确认。
- PDF 导入复制真实文件到沙箱，通过 PDFKit 获取实际页数，渲染原页并按页面实际比例叠加矢量笔迹；离开视口释放位图。缺少原文件的旧导入资料提示重新导入，示例资料明确标注。
- 彻底删除／过期清理同步删除应用内的 PDF 副本，外部文件与越界路径不参与删除；清理失败保留回收站记录供重试。导入正文保存失败时清理无引用副本。
- PDF／主手写画布的“保存并退出”获取当前笔迹并等待存储完成，失败留在阅读器。Markdown／手写／PDF 保存保留收藏、标签、来源和创建时间等元数据。
- 损坏的旧会话按记录隔离，保留有效历史；无效消息、标签与引用字段不会直接进入视图。
- 阅读器“更多”菜单提供保存退出、跳页、图片文字排版、Markdown 文本导出、搜索笔记、工具栏显隐、视图切换和清空批注。尚未实现的 PDF/Word 转换、长图和打印不再作为这些菜单中的成功操作。

## 下一轮优先改进

1. **设备验证与签名构建**：PR 已按请求开放评审，发布前仍需完成上述设备验收。当前仍有框架弃用警告，另行升级 API，不在此 PR 大范围重写 UI。
2. **PDF 提取与排版实测**：已新增选择页范围的文字层/可选扫描 OCR、逐页校对、搜索/RAG 与页码来源。每批最多 30 页，未保存的页面不参与检索；真实扫描件、公式与完整文档覆盖率仍须测试，不能宣称已理解整个 PDF。
3. **排版质量验证**：渲染更完整的 Markdown 预览、展示原文差异和不确定 OCR 字符、用真实资料评测模型的内容保真。当前预览支持标题和逐行阅读，表格／公式／内联样式仍需完善。
4. **复杂编辑并发**：覆盖边读边写中主笔迹与草稿的并发保存、异步读写期间快速切换笔记、异常终止与持久化草稿恢复。
5. **真实文档输出**：Word 正文解析、原 PDF／嵌入批注导出、长图、打印和格式转换需要各自的系统接口和验收，避免只保留看似成功的按钮。
6. **手机性能与触控**：补齐 PDF 缩放／漫游的实测、多页文档滚动与大型图谱性能、无障碍名称和触控区域检查。

因此，此版本解决了 OCR、导入与保存中的关键真实性问题，但不宣称全产品已经达到真机发布标准。

## 2026-10-04 校园学习与上架目标补充

本轮增加课程资料统计、手动/可选 AI 题卡、回忆后查看答案、三档反馈与到期复习。总复习次数与连续掌握次数分别存储；自评是学习记录，不等于成绩。AI 学情上下文读取实际复习摘要，不虚构学习测量。

PDF 使用实际文字层和用户选择的扫描 OCR，页范围限制 30，可取消、逐页校对后保存；搜索结果与 AI 引用携带真实页码，点击可打开原资料页面。RAG 与附加资料仅使用已保存的文字，来源片段命中不代表模型答案必然正确。

学习资料备份保存真实 PDF 与封面附件、笔迹、题卡及校对文字；排除模型密钥、会话、待办与回收站。单附件 16 MB、文件 32 MB，按课程分批。恢复副本以稳定 ID 支持重试，保留已写入资料并补齐缺失题卡，内部唯一双链重连；同名/外部链接保留。不是整批跨文件事务或自动云同步。
