# 墨语隐私与数据说明

更新：2026-10-07。本文与应用内、在线页面由同一份资料生成；编辑 release 下的配置后重新生成。

## 本地学习资料

笔记、导入的 PDF、封面、手写批注、待办、复习卡片、对话与模型配置保存在本机应用目录。应用不要求注册墨语帐号，当前版本没有团队运营的云盘、订阅或广告服务。卸载或系统清理可能删除数据，请先导出学习资料。

## 文件与图片选择

导入资料和选择封面时，由系统文件或相册选择器提供你主动选择的文件。应用将需要长期使用的 PDF 和封面复制到自身目录。图片 OCR 和 PDF 页面提取使用设备系统能力，成功与失败均释放临时图像资源。

## 可选的远程 AI

AI 设置提供自配 API 与云端 AI 目录。云端入口仅为尚未开放的本机目录，浏览或预览不联网、不发送资料，也不改变已启用档案；选择自配接入会新建无密钥、未授权的草稿。只有你填写自配 API 并单独授权后，才向所选服务发送当前问题、用于对话的历史、所选资料和检索片段；智能整理与题卡生成会发送所选文字。语义检索另需主动开启，会发送资料库笔记与已校对 PDF 的文字片段。连接测试会发送测试文字。授权默认关闭，绑定服务地址和协议，修改后需重新确认；取消勾选并保存可撤销后续请求，进行中的请求请在原页面停止。API Key 用于该服务鉴权。服务由你自行选择，其费用、保存期限和数据规则由服务商决定，使用前请阅读其隐私政策，避免发送敏感资料。

## 离线使用与密钥

本地笔记、阅读、OCR 校对、关键词检索、手动题卡和复习反馈不需要模型密钥或联网。模型密钥用 AES-GCM 加密保存，加密密钥由设备系统密钥库管理，不以明文写入模型配置。旧版配置在读取时迁移，失败时保留旧数据并提示，不回退到新增明文存储。系统密钥不可用或更换设备时需重新填写。学习资料备份不包含模型配置、密钥和对话记录；导出文件本身未加密，请保存到可信位置。

## 系统备份与迁移

当前版本关闭系统整包备份恢复，避免包含旧版配置或无法迁移的设备密钥。可在“外观与数据 → 备份与附近传递”导出和恢复学习资料，换机后重新配置模型。卸载前请先导出资料，系统清理和卸载可能删除本地数据。

## 可选的附近传递

只有主动连接附近设备时才申请设备数据同步权限。选择可信设备后，可传递所选课程的正文、PDF、封面、笔迹、已提取文字和题卡；不传递日历、回收站、会话、模型配置或密钥，也不上传至团队服务器。临时传递库开启系统加密，正常关闭页面时清理，异常退出后在下次连接时清理。传递码 15 分钟有效；接收需确认导入副本，已导入资料按本地资料管理。此试用能力依赖系统设备连接，不提供异地自动同步。

## 删除、恢复与反馈

可在本机查看、更正并导出学习资料。删除笔记先进入回收站，彻底删除会清理应用内正文、PDF 和封面副本；复习卡片在课程复习页单独移除，对话在会话菜单单独删除。删除模型档案或清除密钥并保存后移除密钥引用，旧密文尽力清理；卸载/清除应用数据可移除应用存储。外部 AI 授权可在模型设置取消并保存；系统设备权限可在系统设置撤销。本版本不运营用户帐号，无帐号注销步骤。你自行导出的备份、已传递副本及服务商保存的数据需分别删除。反馈请勿公开密钥或私人资料。

## 版本与反馈

墨语是面向校园学习的本地优先开源应用，当前不运营云盘、广告、分析统计或付费订阅，也不在启动或后台自动向团队服务器上传资料。不主动收集设备标识、位置、通讯录或应用列表。AI 结果仅供学习参考，请结合课程原文核对。正式发布者、隐私咨询联系方式和在线政策链接见本页发布信息；应用市场版本须填入真实资料。
