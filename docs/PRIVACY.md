# 墨语隐私与数据说明（发布前核对稿）

更新日期：2026-10-06。应用内入口：“外观与数据 → 隐私与数据说明”。此文档对应当前实现；正式发布前须填入真实发布主体与有效联系方式，并与 AGC 声明一致。项目维护者尚未提供正式发布身份，本文件不代替最终市场声明。

## 保存的数据

笔记、原 PDF 的应用内副本、封面、手写批注、待办与日期备忘、复习题卡、对话、模型档案和设置存储在应用目录。当前无应用帐号、团队云盘、订阅或广告服务，没有接入团队用户行为统计服务。

使用系统文件/相册选择器只读取用户主动选取的内容。需长期使用的 PDF 与封面复制到应用目录。图片 OCR、PDF 页面文字与可选扫描 OCR 由设备系统能力处理；不通过项目的远程 OCR 服务器。

## 可选的模型服务

| 操作 | 可能发送至用户配置的服务的内容 |
| --- | --- |
| AI 对话与伴读 | 问题、参与对话的历史、选中的资料、检索到的片段与来源信息；学情模式可包含待办和复习自评摘要 |
| AI 图片文字排版 | 用户校对后确认发送的识别文字与整理要求 |
| AI 题卡预览 | 所选资料正文及已保存的 PDF 页面文字，最长上下文有截断；生成结果需核对后保存 |
| 主动开启语义检索 | 待索引笔记与已校对 PDF 页面的文字片段，发送至所选向量模型服务 |
| 测试连接 | 配置的模型参数、简单测试内容与服务鉴权信息 |

API Key 用于向所选服务鉴权。服务商、服务地址、模型与费用由用户配置；数据留存、处理地域和使用方式取决于该服务的政策。启用前应核对服务商政策与要发送的资料。切勿把真实 Key 写入公开问题、截图或备份文件。

本地阅读、编辑、关键词搜索、手动题卡与复习不要求 Key 或网络。语义检索默认关闭，AI 题卡默认未同意发送。默认本地并不代表启用 AI 后无外部数据传输。

## 备份、密钥与删除

### 附近可信设备传递（候选功能）

“备份与附近传递”中的试用入口只在用户主动连接时申请 `ohos.permission.DISTRIBUTED_DATASYNC`。设备列表来自系统可用的可信设备；不会扫描、绑定陌生设备或要求墨语帐号。所选课程的正文、真实 PDF、封面、笔迹、已提取页面文字和题卡通过系统分布式数据能力传至所选设备，不经团队服务器。待办/日期备忘、回收站、会话、模型配置和 Key 不在传递包内。

临时分布式 KV 库开启系统加密、关闭该库的自动备份和自动同步。正常关闭页面会删除临时条目，异常退出后的残留在下次连接时清理。传递码 15 分钟后拒绝导入，过期不等于系统立即擦除残留数据；清理失败仍需下次连接重试。接收先检查完整性，再由用户确认导入副本；导入后的本地资料会保留，按通常删除机制管理。学习资料文件导出仍是明文，系统应用备份仍按下文规则处理。

两端需相同应用身份及有效签名、系统可信组网和授权。该功能不提供异地云同步，不自动合并编辑、不同步删除；本轮尚未执行双真机互通验收，不能据模拟接口通过承诺设备间稳定可用。

### 文件与系统备份

模型 Key 保存在应用私有配置，当前未增加独立的密钥加密层；不宣称应用自身提供密钥加密或外部服务零留存。

当前工程的系统备份配置 `allowToBackupRestore` 为 true，允许设备系统备份/恢复应用数据。系统备份与本文的学习资料导出不同，其范围、目的位置与传输规则由设备系统控制，可能包含模型配置；本轮未验证系统迁移或密钥排除。发布前须核验实际规则与隐私声明，不得据手动导出排除 Key 宣称所有备份均排除 Key。

学习资料备份包含笔记、原 PDF、封面、笔迹、已提取页面文字与题卡。待办/日期备忘、回收站、会话、模型配置和 Key 不包含在该备份中。文件为明文 JSON 与编码附件，编码不等于加密。通过系统选择器保存到用户选择的位置，用户负责管理该位置及其云盘的访问权限和共享设置。

随包示例只备份已有正文与笔迹，没有原 PDF；恢复后保留示例标记。真实导入的 PDF 若原文件缺失，导出会报错，不生成伪装成完整资料的备份。

恢复创建副本；不覆盖现有资料。每份资料独立保存，中断可能已恢复一部分，重试同一备份会补齐缺失项；不会声称整批导入为原子事务。

笔记先软删除至回收站，彻底删除会清理对应的应用内正文、PDF 与封面副本。复习卡片可单独移除，应用不会删除外部相册或文件选择器中的原文件。卸载、清除应用数据或系统清理可能移除应用目录；先导出并验证备份。
