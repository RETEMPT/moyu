# 新建、助手与伴读交互实施方案

日期：2026-10-09。先完成调研与代码审计，再实施，追加到现有 PR #4。

## 调研与取舍

- [Notion 官方写作指南](https://www.notion.com/help/guides/notion-ai-for-docs)：借鉴上下文引用、任务入口和结果核对；本地摘录不冒充大模型总结、翻译或推理。
- [OpenAI 官方功能入口](https://learn.chatgpt.com/docs/features)：借鉴输入框附近的资料/工具分组与独立会话操作。当前官方页面未明确完整加号菜单清单，不能以此宣称功能等同 Codex；应用只展示有实现的能力。
- [AstrBot 官方项目](https://github.com/AstrBotDevs/AstrBot)：其模型接入、知识库与扩展各有边界。本项目借鉴能力分区与配置校验，不引入需要个人团队运营的机器人服务、插件市场或执行沙箱。
- [DeepSeek 首次调用](https://api-docs.deepseek.com/zh-cn/)及[百炼 API Key 指引](https://help.aliyun.com/zh/model-studio/get-api-key)、[千问首次调用](https://help.aliyun.com/zh/model-studio/first-api-call-to-qwen)：教程使用官方入口；区分完整请求地址和 SDK Base URL，百炼地域、密钥、模型须匹配。
- 用户提供的伴读参考图：文档与对话并排、紧凑顶栏、正文优先、底部输入。跟随应用主题；不添加未实现的生成/导出按钮。

## 实施顺序与验收

1. 新建表单：明确文字笔记/手写白板，图标配文字；保留输入，不再聚焦清空。可选择所属项目（现有 category 字段）和主题标签（tags），确认按钮写“创建”。失败保留表单。
2. 助手菜单：原生按钮承载菜单，避免自定义组件绑定；新建对话置于右上角更多左侧。加号分资料、离线任务和模型任务；模型任务未配置/授权或本地模式时标灰。更多支持真实会话操作和设置。
3. 资料引用：会话内关键词选取，搜索标题、项目、标签及可用正文；扫描 PDF 只使用已校对文字，不把文件名当内容。结果选择后成为引用，取消/返回只关闭选择区。
4. 笔控：普通笔、荧光笔、橡皮独立记住宽度；滑杆调节不改工具；选中图标、文字、顶栏、浮球和快捷橡皮状态一致。调整参数先结束当前笔触，历史笔迹不重写。
5. 教程：应用内图解配置步骤、DeepSeek/百炼官方链接、完整请求地址示意、测试与常见故障；不内置或展示真实密钥。
6. 伴读：精简标题、引用范围、动作和正文卡片；保持多轮上下文，保存批注不打断会话。PDF 没有校对文字时给出真实提取入口；不声称已经读取扫描图片。
7. 验证：执行工作流、PDF、上架前置检查与 ArkTS 发布构建；补充状态切换、菜单绑定、检索、授权、保存不打断和空文本回归。真机弹窗、触控和笔事件仍需设备验收，自动测试不能代替。
