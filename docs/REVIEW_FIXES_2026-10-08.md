# 2026-10-08 审核问题整改

依据团队提供的版本 1.0.0 华为审核截图；截图记录测试环境为 HarmonyOS 6.1.1(API 24)、Pura 80 Pro+。本文日期为整改工作日期。“已实施”指源码和检查完成，重新送审结果与真机验收另行记录。

## 问题与解决方案

| 反馈 | 原因与影响 | v1.0.3 已实施的整改 |
| --- | --- | --- |
| AI 页面显示未开放且无结果 | 未运营服务占据主要路径 | 默认离线助手提供检索、摘录、任务候选和资料概览；空库给出步骤。云服务只在设置显示未开放，不作为默认问答路径 |
| AI 要求 API Key，审核无法体验 | 唯一问答来源依赖外部模型 | 无账号/Key 完成本地流程；保留可选自配 API，按地址独立授权，不要求团队运营云服务 |
| 首次已有测试资料 | 启动自动注入样例 | 首次笔记、项目、待办为空。模板由用户选择创建；真实阅读测试 PDF 只在设置主动导入。升级不静默删除用户资料 |
| 新建日记/笔记不生效 | 类型回调与保存顺序有误 | 全局/项目/模板共用流程，等待正文及快照写入后打开；阻止重复提交，失败保留输入。文档默认只读，编辑/批注由用户进入 |
| 工具含义不清、菜单难操作 | 图标缺少说明，操作分散 | 首页、编辑、笔工具补短标签；项目与二级菜单居中，图标和名称明确；墨客 ＋ 汇总操作，删除/清空/撤回需确认 |
| PDF 找不到 | 历史示例只有元数据，没有实际原件；墨客旧导入只挂载临时引用 | 新增真实两页 PDF 手动导入；墨客导入先保存资料库再引用。无法从仓库恢复不存在的旧原件，个人文件需从本地备份或原路径重新导入 |
| 白板左右拓展卡顿 | 扩大画布与重复全量绘制 | 固定视口、世界坐标、可见笔迹筛选、16ms 合并重绘；允许负坐标，不再构建巨大画布 |
| 顶栏占空间、退出反复确认 | 始终展开、未区分实际改动 | 阅读下滑收缩、空白点击展开；输入/批注时保持。未修改/已保存直接退出，待保存主文档及草稿使用简化面板 |

本地助手是规则检索和原文摘录，未内置端侧大模型。自配 API 只有用户配置、授权并主动选择后才请求；云 AI 和云备份未开放，本地备份保留。AI 与阅读页的共享解析器保留中文、编号、表格、代码及多段公式原文，未宣称完整 LaTeX 图形排版。

## 响应与保存

本地扫描定期让出事件循环，支持停止。自配 API 首个有效流事件上限 45 秒、事件间隔 30 秒、总时长 180 秒；非流式 60 秒，远程向量超过 12 秒回退关键词。取消、页面切换和会话删除保护迟到结果，不自动改写模型 ID。

新建、PDF 导入、消息删除和退出等待实际写入，失败保留可重试状态。旧快照不能复活已删除会话；阅读模式的任务勾选不会直接修改文档。上述工作量和时限控制不是端到端速度实测。

## 鸿蒙与星闪笔

使用 ArkUI、PDFKit、Share Kit、系统文件选择器与 HUKS；主题跟随系统、键盘避让与 Ctrl+F 保留。系统完成笔配对，应用通过 `SourceTool.Pen` 分流笔/手指/手掌、压力和历史点；已完成与当前笔迹分层，增量平滑绘制。Penkit 双击切换橡皮、轻捏工具，分屏按最近落笔画布处理，退出注销。撤销/重做最多 50 步，缩放/平移兼容旧笔迹。

尚无目标 MatePad/星闪笔的实际延迟、防误触、压感、悬停和系统分享验收，不承诺与华为笔记相同体验。应用不自行管理星闪链路、未接入小艺或自动云同步。接口依据：[Penkit](https://developer.huawei.com/consumer/cn/doc/doccenter-references/api/pen-stylusinteraction)、[Share Kit](https://developer.huawei.com/consumer/cn/doc/doccenter-capabilities/share-utd-text)。
