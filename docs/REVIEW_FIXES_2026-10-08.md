# 2026-10-08 审核问题整改

依据团队提供的华为审核截图：版本 1.0.0，报告生成时间 2026-10-08，测试环境为 HarmonyOS 6.1.1(API 24)、Pura 80 Pro+。下表中的“已修复”表示源码和自动检查完成，重新送审结果与真机验收需单独记录。

## 四项问题与解决方案

| 审核反馈 | 原因与影响 | 已实施的整改 |
| --- | --- | --- |
| AI 页面显示云端未开放，功能体验不完整 | 页面暴露未投入运营的服务目录，进入后无法获得结果 | 移除生产模块中的云端目录。默认提供本地助手，支持原文检索、要点摘录、待办提取、资料概览；空库与无匹配结果给出可执行的下一步 |
| AI 连接需 API Key，审核无法体验 | 实际问答依赖外部模型，团队无法提供长期可用的云服务 | **release 模式只提供离线能力**，不显示自配模型、生成题卡或 AI 排版入口。网络策略同时拒绝远程聊天、连接测试和向量请求，旧远程配置也不会在发布模式激活。自配服务仅留在 debug 开发模式 |
| 首次进入已有资料与笔记 | 启动时自动注入样例笔记与项目 | 首次笔记、项目为空，示例移到 `tools/fixtures`，不进入生产源码。空白模板只在用户主动选择后创建；升级保留既有内容，不静默删除可能已被编辑的资料 |
| 新建日记/笔记不生效 | 全局新建丢失所选类型；项目新建未等待保存且可能错误提示成功；模板入口遗漏回调 | 全局、项目、模板共用创建流程，正文与目录快照写入成功后才打开。创建期间显示忙碌并阻止重复提交；失败保留输入与错误信息，允许重试。空白文字笔记直接进入编辑，手写笔记直接打开稿纸 |

采用离线能力，是当前无需运营云端的可交付方案。本地助手使用规则与关键词定位原文，不是端侧大模型，不提供无资料依据的开放问答，也不将手写笔迹冒充已识别文字。未增加帐号、团队 API Key 或自建推理服务器。

## 响应与保存

- 中文问题提取检索词，命中的 Markdown 引用使用实际正文行号；PDF 只使用已经提取并校对的文字与真实页码。
- 本地资料扫描定期让出事件循环，支持停止；离开页面、切换会话或文档后，不接受旧请求的晚到结果。
- debug 自配服务：首个有效流事件最多等待 45 秒，事件间隔 30 秒，单次流式请求总上限 180 秒；非流式问答上限 60 秒，远程向量检索超过 12 秒回到关键词结果。停止会终止请求，保留已接收的文字，不自动更改用户模型 ID。
- 新建与退出保存等待实际持久化。切换阅读资料时保存快照使用原文档身份，避免写入新文档；保存失败显示结果，不能把未写入的数据标为“已保存”。
- 这些是超时与工作量控制，不是端到端延迟实测。长资料的启动、OCR、PDF 位图渲染和硬件落笔延迟仍需真机报告。

## 星闪手写笔与书写体验

使用 HarmonyOS 的笔输入与 Penkit 事件，配对由系统完成。是否通过星闪连接不改变应用的笔触入口；本轮没有添加蓝牙/附近设备配对权限。

| 体验目标 | 实现 |
| --- | --- |
| 笔写、手指浏览 | 默认仅 `SourceTool.Pen` 落墨，手指书写需主动开启；笔接触期间的手掌事件不会结束或追加笔迹，多指触摸取消手指书写 |
| 压感与笔迹连续 | 归一化压力、缺失数据回退、历史触点补采样；实时和重放使用同一套中点曲线 |
| 快速落笔 | 历史笔迹层与当前笔迹层分开；移动事件只绘制最新曲线段，不逐点重绘整页或触发整页状态更新 |
| 笔身操作 | 双击切换橡皮擦并恢复之前的笔工具；轻捏呼出工具。分屏按最近落笔的画布确定操作对象，离开页面注销事件 |
| 擦除与恢复 | 手写橡皮擦使用透明擦除；PDF 按笔迹线段命中擦除，一次擦除手势计作一次历史操作；支持撤销、重做及清空恢复，最多 50 步 |
| 缩放与位置 | 双指缩放，放大后可滚动平移。PDF 笔迹保存归一化坐标，手写新笔迹保存参考宽度，缩放和窗口变化时重新映射；旧笔迹继续按旧格式读取 |

接入的是系统公开能力，不能据编译或模拟事件宣称已达到华为笔记原生的硬件延迟与压感表现。不同型号是否提供双击/轻捏事件，需要目标 MatePad 与星闪手写笔验证；无该事件时仍可使用屏幕工具栏。悬停预览、倾斜笔锋、系统级预测笔迹、手写转文字和硬件震动不在本次实现范围。

官方接口依据：[stylusInteraction 双击与轻捏](https://developer.huawei.com/consumer/cn/doc/doccenter-references/api/pen-stylusinteraction)、[NearLink 系统能力](https://developer.huawei.com/consumer/cn/doc/HarmonyOS-Guides/nearlink-introduction-guide)。具体控制行为与设备支持以系统和笔型号为准。

## 指引与文字精简

“外观与数据”新增“使用指引”，涵盖新建、手写笔、离线助手、备份。发布版不出现开发模式的模型配置步骤。移除“云端尚未开放”、模型系列目录与自动更换模型的错误提示；文字编辑器移除未接通的插入按钮，离线来源栏隐藏模型工具箱。“AI 墨客”缩为“墨客”，新建入口统一说明文字/手写，PDF 不再被统一标成考研真题。完整操作见 [使用指引](USER_GUIDE.md)。

- 未签名构建只用于开发验证；仍需有效发布签名、主体/隐私网址、对应包的真机记录及真实截图。检查器继续保留这些提交门槛。

真机复测顺序：先使用干净安装、断网、无 Key 的 release 包完成“新建文字 → 重启 → 新建手写 → 离线助手 → 导入 PDF”；然后在目标 Pad 验证星闪笔的落笔、压感、手掌接触、双击、轻捏、分屏焦点、横竖屏、PDF 放大/平移、撤销重做和保存重开。更新双端证据模板中的 `first_launch_empty`、`local_assistant`、`create_note`、`stylus_handwriting`；没有执行的项保留 TODO。

审核人员可从空白页面自行输入一段课程文字，再使用本地助手完整体验，不需要团队提供模型帐号或 Key。商店介绍与审核路径已按此范围调整，见 [市场资料](../release/STORE_LISTING.md)。
