# FlowMind（墨语）v1.0.3

本次更新让无 API 的离线使用、可选大模型配置、文档阅读和手机/Pad 操作更完整。1.0.2 为未发布的中间候选，最终更新统一发布为 1.0.3。

## 更新内容

- **离线与 AI**：默认本地助手，无需登录或 Key，提供原文检索、摘录、任务候选和出处。设置可授权自配 API，保留原有 L1/L2/L3、工具与题卡能力；本地与模型回答统一标题、列表、表格、引用及代码/公式块，公式原文不丢失。远程请求有超时、停止和迟到结果保护。
- **设置与备份**：独立设置页分为资料库、指引、主题、AI、云服务、协议与关于。云服务、云 AI、云备份显示“未开放”，保留本地文件备份与恢复。
- **图标与菜单**：重绘浅深色应用图标，统一 60 个工具图标与文档封面；首页及文档工具增加短标签。项目、文档与墨客加号菜单居中，动作有明确图标和名称。新对话、资料导入与管理集中到加号；删除、清除和撤回需确认，删除后迟到回答不会复活对话。
- **阅读与保存**：文档默认只读，进入编辑/批注后才能改动；无改动或已保存时直接退出，有待保存内容时使用简化面板等待主文档和草稿写入。阅读时下滑收缩顶栏，点击空白展开；打字和批注不触发收缩。保留中文、英文、编号、表格与代码内容。
- **白板与笔控**：改用固定视口、世界坐标、可见笔迹筛选及合并重绘，左右浏览不再扩建巨大画布。保留压感、历史采样、笔指分流、双指缩放、50 步撤销/重做；Penkit 双击切换橡皮、轻捏工具按当前画布响应。
- **PDF 与日历**：墨客外部导入先持久保存到资料库再引用。设置可手动导入真实的两页阅读测试 PDF，首次不自动塞入测试资料。日历显示农历和节日，2026 年显示已核对的法定休息/调班；其他年份不推测调休。
- **工程清理**：移除无调用的旧设置页、工具栏与临时导入服务；更新应用内外指引、隐私材料和发布检查。发布附件只包含应用包、安装说明、构建信息与校验值。

## 下载与安装

[v1.0.3 发行页面](https://github.com/RETEMPT/moyu/releases/tag/v1.0.3)。手机与 Pad 共用一个应用身份和 APP。

| 附件 | 内容 |
| --- | --- |
| `FlowMind-1.0.3-HarmonyOS-unsigned.zip` | release APP、从同一 APP 提取的 HAP、安装说明、构建信息与内部校验值 |
| `BUILD_INFO.json` | 源码提交、实际包元数据、验证范围、SHA-256 和 CI 链接 |
| `SHA256SUMS.txt` | 附件及包内文件的 SHA-256 |

包名 `com.retempt.flowmind`，版本 `1.0.3` / `1001003`。兼容 SDK `6.1.1(24)`、目标 SDK `26.0.0`。这是**未签名开发构建**，设备安装需要适用签名；正式市场提交还需发布资料与验收。检出标签后在 DevEco Studio 配置设备签名，再构建：

```powershell
.\build_hap.bat -StudioDir "<DevEco Studio 安装目录>" -BuildMode release -AppPackage -Clean
```

升级应保持包名和签名一致，先导出本地学习资料；签名不同不能直接以卸载方式覆盖重要资料。

## 验证与边界

227 项工作流、11 项发布规则检查、图标/隐私材料校验及干净 release APP 构建通过。实际包身份、版本、设备、权限、备份配置和发布模式由预检核对；构建仍有既有框架弃用告警。具体提交、摘要和 GitHub CI 记录见附件 `BUILD_INFO.json`。

服务检查使用平台替身，本轮没有完成手机/Pad、星闪笔、系统分享接收方与双设备传递的真机验收；不承诺与华为笔记相同的硬件延迟。本地助手是规则检索与摘录，未内置端侧大模型；公式块保留可复制源文，未实现完整 LaTeX 图形排版。团队云服务仍未开放。

本地备份是明文资料文件，包含原 PDF、笔迹、封面、已校对文字与题卡，不含对话、待办/日期备忘、回收站和 API 配置/Key；单附件上限 16 MB，总文件上限 32 MB。卸载或换机前在“设置 → 资料库 → 本地备份”导出并检查可恢复。
