# 鸿蒙原生适配与验收

v1.0.3 使用 ArkUI、Penkit、PDFKit、Share Kit、系统文件选择器、HUKS 和应用沙箱。默认本地助手不依赖 API；设置可授权自配 API，团队云服务/云 AI/云备份尚未开放。

| 场景 | 当前实现 | 设备验收重点 |
| --- | --- | --- |
| 手机、平板操作 | 自适应外壳；44vp 图标按钮、系统提示、无障碍名称；狭窄笔工具栏横向滚动 | 竖屏/横屏、分屏窄窗、大字体、读屏与笔悬停 |
| 文档菜单 | ArkUI `bindMenu`，按文档类型展示操作 | 菜单关闭、返回手势、保存并退出 |
| 主动分享 | Share Kit 原生选择器；当前文字或应用内原 PDF | 支持的接收方、取消、异常反馈；PDF 不含应用内笔迹 |
| 手写笔 | `SourceTool.Pen` 区分笔与手指；压力/历史触点；Penkit 双击与轻捏 | 星闪笔系统配对后，在手写与 PDF 中分别验证双击、轻捏、压力、防误触 |
| 手写响应 | 增量曲线绘制、独立已完成/当前笔迹层、撤销/重做、缩放与平移 | 长笔迹、连续书写、边缘落笔、多指/手掌并发；测量实际延迟 |
| 主题与图标 | 跟随系统深浅色；API 26 起尝试切换桌面备用图标，低版本保留默认图标 | 冷启动、主题切换、启动图、桌面缓存 |
| 键盘与编辑 | Ctrl+F 全局搜索；编辑器随键盘调整布局，离开后恢复原避让模式 | 外接键盘、输入法、编辑焦点与返回 |
| 导入与保存 | 系统选择器、PDFKit 原页、沙箱正文与快照保存；失败保留输入 | 导入真实 PDF、新建空笔记、重启恢复与升级 |
| 备份与附近传递 | 用户主动导出/恢复副本；可信设备上的手动资料传递 | 同签名双设备、权限拒绝、中断重试、重复导入 |

## 无 API 的操作路径

首次空库 → 首页文字或手写图标新建 → 写入并等待保存 → “墨客”引用真实资料 → 本地搜索、摘录与待办候选。无需登录、Key 或联网。PDF 要先提取并校对文字；扫描页需 OCR。待办候选由用户确认，本地助手不提供大模型生成式问答。

独立设置页提供资料库、指引、主题、AI、云服务和协议。文档默认只读，工具有短标签；阅读下滑收缩顶栏、空白点击展开，编辑/批注期间保持。白板采用固定视口与世界坐标，不随左右浏览扩建巨大 Canvas。debug/release 均可主动选择授权自配服务，默认本地；失败或停止不会改写模型配置。

## 笔控验收

1. 在系统完成笔配对，分别打开空白手写笔记与实际 PDF。先在目标画布落笔，再操作笔身，分屏另一侧不应接收事件。
2. 连续写字并靠掌，检查笔/手指分流；默认笔写、手指浏览，开启手掌按钮后检查手指书写，双指缩放不应生成多余笔迹。
3. 双击切换橡皮擦，再双击回到之前工具；轻捏展开工具。切换焦点、退出阅读器后复测，事件不应重复订阅。
4. 连续写长笔迹、旋转设备、缩放/平移、擦除、清空，再撤销/重做；保存退出并重启核对实际笔迹。
5. 记录设备、系统/笔固件、压力效果、测得延迟及截图。公开事件支持情况由设备决定，未支持的事件不能通过应用模拟成硬件能力。

代码和服务回归已覆盖事件生命周期、输入分流与历史恢复，SDK 已验证接口类型；当前没有连接真机。尚不能声称与华为笔记具有相同延迟或笔迹引擎。应用不自行管理星闪链路，也没有接入小艺、应用接续或自动云同步。

接口依据：[Penkit 笔身交互](https://developer.huawei.com/consumer/cn/doc/doccenter-references/api/pen-stylusinteraction)、[Share Kit 文字分享](https://developer.huawei.com/consumer/cn/doc/doccenter-capabilities/share-utd-text)。版本、签名与下载见 [v1.0.3](RELEASE_1.0.3.md)。
