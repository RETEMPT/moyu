# 墨语产品、商业与开发文档

墨语围绕课程资料的阅读、书写、整理和复习构建学习工作台。文档介绍产品解决的问题、已有设计、商业价值，以及云AI、跨设备资料管理和内容生态的发展方向。

当前版本为 1.1.1，主应用新增本地复习增强。独立 AI 学习实验未接入主软件，离线结果准备层尚无导入入口；团队托管云AI、收费云盘和公开资料库仍为规划。各项状态与数据边界统一以[产品范围](../PRODUCT_SCOPE.md)为准。

## 阅读、记录与未来服务

本地工作台提供多格式资料、双文档对照、独立笔迹与稿纸、OCR校对、规则排版、搜索和复习。用户无需注册即可使用，资料可主动备份和导出。

未来将逐步连接公开资料发现、私人存储和云AI辅助，使资料获取、研读与学习成果积累之间保持联系。云端能力作为用户主动选择的扩展，与基础本地体验相互衔接。

## 文档维护

版本与包名以 `AppScope/app.json5` 为准，设备和权限以 `entry/src/main/module.json5` 为准。产品能力变化时同步修改范围、开发说明、用户指引和测试。规划变为已实现，须有相应源码、可操作功能和真实验证依据。

产品、商业、创新、架构和开发规范在仓库公开维护，围绕用户价值、实际设计与后续演进持续完善。
