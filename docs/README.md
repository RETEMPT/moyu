## 当前实现与规划

- **当前本地应用**：多格式资料、通用双文档工作台、独立笔迹与稿纸、系统OCR和规则排版、项目／搜索／双链图谱、手动题卡、文件备份和主动分享。
- **后续商业方向**：公开资料发现、私人付费存储、团队托管云AI套餐与机构服务。云端AI可作为独立付费服务，不要求用户同时购买云盘。
- **尚未实现**：云AI、商业网站、账号支付、自动云同步及客户端云连接。方案、价格和业务数据均注明假设或待验证，不计入当前功能完成度。

用户无需注册即可使用当前应用。后续网站和云AI账号只用于用户主动选择的服务；基础本地资料可独立阅读、编辑和导出。当前隐私政策描述当前本地版，任何实际云接入均需先同步用户说明和数据处理边界。

## 文档维护

版本与包名以 `AppScope/app.json5` 为准，设备和权限以 `entry/src/main/module.json5` 为准。产品能力变化时同步修改范围、开发说明、用户指引和测试。规划变为已实现，须有相应源码、可操作功能和真实验证依据。

产品、商业、创新、架构和开发规范在仓库公开维护。上架流程、比赛提交日期、交付清单、签名与内部证据保留本地，不作为本公开文档的一部分。
