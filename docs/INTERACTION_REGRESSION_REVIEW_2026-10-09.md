# 菜单、笔控与记录侧栏回归

依据用户 09:48–10:06 的 Pad 截图及“文档更多无法打开稿纸/AI”的反馈。修改追加到 PR #4，不更改已发布版本号。

## 根因与实现

| 问题 | 根因 | 最终行为 |
| --- | --- | --- |
| 选中橡皮却高亮普通笔 | Builder 按值传递 selected，生成代码关闭在初值上 | IconButton 子组件 @Prop 订阅当前工具；背景、图标、小字同步 |
| AI 加号/更多、文档更多不展开 | 箭头包装未被 SDK 转换成原生 builder 对象 | 原生 Button 显式开关，直接具名 Builder；编译后生成 `{ builder: …bind(this) }` |
| 双指无法浏览白板 | 手指笔迹接触锁与祖先捏合手势互相拒绝 | 同一触点处理器取消未完成手指笔迹，然后同时平移与缩放；笔接触拒绝手掌导航 |
| 缩放后不能单指继续写 | 抬起事件可能仍包含刚离开的触点 | changedTouches 核对全部释放；Cancel 同样清除导航状态 |
| 稿纸和正文各有工具栏，顶栏又保留阅读选项 | 三处各自管理按钮 | 批注顶栏取代五个阅读选项，操作目标可切换；返回先保存并恢复阅读 |
| 项目头溢出、对话记录拥挤 | 项目操作与模式切换挤在同一行 | 项目头只放项目操作；记录图标打开完整侧栏页，外点或关闭恢复原状态 |
| 快速切换会话后旧结果覆盖新会话 | 读取缺代次保护，保存等待后才取当前消息 | 读取校验请求代次/选中 ID；保存预先深拷贝并串行，晚到回写只刷新列表 |

区域擦除用透明掩膜，笔画擦除用扫过线段的命中检测；取消恢复、完整手势撤销、旧 referenceWidth 笔迹均有回归。隐藏嵌入工具栏后，延展与清空入口移到顶栏笔设置，只操作选中画布。

## 验证边界

- `tools/verify-workflows.mjs`：354 项服务/视图方法测试，平台依赖使用替身。
- `tools/verify-pdf-chain.mjs`：30 项原件导入、恢复、批注和保存专项。
- `tools/verify-app-market.mjs`：11 项规则；生成隐私资源与 68 个 SVG 图标一致。
- `tools/verify-compiled-ui.mjs`：先构建 release，再执行 SDK 实际生成的组件代码。6 项用更新订阅及原生组件适配器检查按钮/图标高亮、菜单 builder 与可点击菜单项、阅读控件替换和返回恢复、稿纸/AI 分屏入口、记录搜索与选择，以及首页首批节点与封面菜单。

智能提取及资料管理的额外范围见 [端侧评估](MARKER_HARMONY_REVIEW_2026-10-09.md)。

编译后适配器不测原生命中范围、GPU、手势裁决、动画帧率、PDFKit 位图或物理笔事件；不能将它当作真机测试。GitHub CI 执行前三类回归，SDK 编译与编译后 UI 检查在本机执行。

本机复验需向脚本传 `--typescript <SDK typescript.js>`；编译后脚本默认读取 release 缓存，也可传 `--compiled-dir`。应先重新编译修改后的源码，避免验证旧缓存。

## 真机复验顺序

1. 手机/Pad 打开 AI，键盘弹出前后分别点加号、模型和更多；选择、外点、系统返回后可再次打开。未配置模型时生成任务标灰。
2. 点记录图标，搜索、置顶、删除、选择；外点、侧栏关闭、再次点入口均恢复侧栏。手机底部原五项导航保留，旋转/窄窗口不溢出。
3. 文档右上更多分别开稿纸、AI、仅正文。进入批注只剩一组顶栏，选择正文/稿纸，换笔/调宽/擦除/撤销只影响目标。红色返回保存后恢复五个阅读选项；再次返回关闭文件。
4. 白板单指写到边缘抬笔，双指平移/缩放，全部抬起后继续单指写；取消触点、笔接管手指、手掌靠屏均不产生尾巴或移动笔页。
5. PDF 两种擦除、快速扫过、撤销重做、切页、模式/宽度切换、最后一筆、重启重读；坏原件或坏笔迹仍禁止覆盖。
6. 慢存储下快速切换记录、保存失败重试、读取失败新建，旧消息不进入新记录，原记录不被空白覆盖。

当前 HDC 无连接目标，尚未执行以上真机步骤；APP 为无正式签名的 phone/tablet 共用开发包。正式发布前需记录同一候选包的设备结果。
